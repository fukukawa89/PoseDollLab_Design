机械装配：从摩擦副开始

工具准备：游标卡尺、小尖嘴钳、1.5/2/2.5/3 mm内六角扳手；小螺钉的实际六角孔另核对。轴肩螺钉使用你确认的 3 mm 扳手。不要把长的M3普通螺钉当作轴肩螺钉替代。

  1. 先验配：M4垫圈能自由套过Φ4光杆，M3垫圈能自由穿过M3螺纹；螺母在外面先试拧。不要靠拧紧强迫不合适的垫圈通过。
  2. 预装隐藏螺母：把六角螺母放进侧开的螺母槽，确认平面贴合。合拢两个座半件之前，先检查以后是否还能放入相应螺母。
  3. 摩擦堆叠顺序：从轴肩螺钉头向螺母看：M4普通平垫圈 → 两片反向A8碟簧 → M4大垫圈 → 活动转臂/叉架的摩擦耳 → M4大垫圈 → 固定座承压台阶 → M3大垫圈 → M3螺母。先轻预紧并试转，暂不安装磁铁和PCB挡住调节入口。
  4. 垫圈朝向：两片M4大垫圈的光滑面朝塑料活动摩擦面。M3大垫圈的平整面朝塑料承压台阶；有明显毛刺的边不能压入塑料。M4普通垫圈平整面朝碟簧。去掉突出的毛刺，不人为打磨改变厚度。
  5. 碟簧朝向：本版CAD采用两片靠孔的小内圈相接，两侧大外圈分别朝相邻平垫圈；两片方向相反，不能像两个碗一样同向套叠。以下剖面只是放大的认件图。

轻预紧后要能顺畅摆动。再逐步增加到“容易调整、放手尽量不掉”的状态。没有已经标定的拧紧扭矩，不要靠大力拧死获得保持力，也不要把碟簧压平。6 mm螺纹已经是本版使用的尺寸，不需要再找7 mm。

多轴叉架、磁铁和传感板

  1. 每个多轴机构先把下环 C14 放入下叉 C01，再放上叉 C02，最后安装上环盖 C15与固定小螺钉。环架的让位形状有方向，参照对应部位的分解图，不凭左右外观猜测。
  2. 有限旋转模块先放入带挡肩的转子，再合拢两半壳体；径向摩擦块与M3调节螺钉单独调节。这里没有使用碟簧替代摩擦块。
  3. 调好轴肩预紧后，装可拆磁铁座、径向磁铁和磁铁盖。磁铁由实体盖保持，胶水不能替代盖子与紧固件。
  4. 依次装板托、传感PCB和板夹；PCB元件面朝磁铁，FFC接口朝外。PCB只能用正常实体旋转安装，不能把镜像后的电路板当作可制造零件。
  5. 插FFC前打开锁扣，按接口接触面方向插到底再闭合。短尾线只形成一次圆弧弯曲，离开板后的活动运动交给软导线；不要反复掰折FFC或在焊点处折弯。

把分段连接成整机

按“骨盆和两腿 → 腰胸与头 → 左右锁骨与手臂 → 背部设备”的顺序装。P编号对应的是实际打印件，有些座已经与长连接架融为一件，不能再额外加一套独立座。安装新分段前，先完成会被遮住的螺母、摩擦预紧和磁铁固定。整体放在软垫上并用手托住悬空分段，最后再轻调各轴阻力。

现有数字证据包括单模块的分步装配路径与整机离散动作；完整人偶的所有手工工具姿态、拆装顺序与公差仍需这批样机验证。若某处需要硬掰塑料才能安装，记录P编号和照片，不能把它当作“紧一点正常”。

背部设备与六条线束

中央板装在胸背盒，四颗M2固定。XIAO焊接在载板上时，模块PCB底面离载板顶面4.0 mm，可用打印间距块暂时定位，焊完取出。降压模块用自己的两个对角安装孔固定在盒盖内侧，元件朝盒内。盒盖外贴FPC天线；同轴线留松弛，不夹在盖缝。

电池放在腰后盒，保持USB口可用。只使用5V输出，不用PD升压触发器。USB弯头伸出电池端面不得超过16 mm。外置G0装桌面小盒，USB数据线连接电脑。身体控制器烧录时先断开电池，避免同时给装配中的板件送电。

发给线束厂的加工要求

  • 按 harness/cut_and_binding_plan.json 的J号、节点号和逐段长度制作。26/24AWG数字越小线越粗；采用柔软多股线，避免单股硬线。
  • 沿关节的电源/地使用连续24AWG主线并分支，信号用30AWG；每个传感器FFC焊接转换处用6根32AWG短引线，长度不超过40 mm。转换区不超过CAD的5×5×0.9 mm外包络，补强与绝缘由工厂完成。
  • GHR-06V-S使用SSHL-002T-P0.2端子，线径仅支持26–30AWG、绝缘外径0.76–1.0 mm。控制器插头先用40 mm长26AWG电源短线，再在插头外转接24AWG主线；不能把24AWG直接塞进GH端子。
  • PHR-2/PHR-3使用SPH-002T-P0.5S端子，24AWG绝缘外径不超过1.5 mm。J8按板上针号为GND、VIN5、VOUT3V3连接降压模块；J7为5V输入，按丝印确认正负。
  • FFC为6P、间距0.5、宽3.5、厚0.2、长15 mm；端部补强长度至少3.5 mm。折弯半径2 mm只作为一次成形候选，须由线束厂确认该材料可成形，不能把折痕当动态铰链。
  • 标签标出J1.01等节点号和线向。做逐针导通、相邻针绝缘、拉力与外观检查后交付。每个焊点单独绝缘；扎带固定在静止打印架上，焊点与FFC不承受活动拉力。

端子范围依据 JST GH资料、JST PH资料。供电预算已经计入细短线、连接器、连续分支和板上走线；预算最小余量约42 mV，不能用计算值替代最远端电压实测。

在关节旁整理服务环

每段长度包含最大端点跨度、约半径12 mm的一圈余量以及接头余量。把软线绕成松弛的外侧U形/圆弧，放在叉架开口的外侧，轻绑在静止架上。逐一把该关节摆到两端，观察线既不拉直，也不进入两块塑料的夹缝。肩/髋有多轴组合运动，要检查组合姿势。这部分没有通过柔性线缆力学仿真，实际绕法、手感与疲劳是本批的必测项。

电子调试：先诊断，再启用保存

  1. 电子厂先不接传感器，确认5V输入极性、降压模块3.3V、中央板无短路。逐条加入J1–J6，记录电流和最远一块板的电压。AS5048A工作电源必须维持在3.0–3.6V范围。
  2. 读取两个XIAO的真实MAC地址，分别贴BODY、G0标签。默认固件未设置真实对端，不能直接把默认二进制当成已配对设备。
  3. 在仓库根目录运行配对模板工具，输入真实MAC。BODY与G0互相绑定后，分别在新的BuildRoot编译并烧录；不要在已经保存旧MAC的构建目录里重复用新defaults覆盖。
  4. 电脑端先运行诊断采样，逐个实际关节做标号确认。诊断数据不是有效PDS1姿势，不会被保存为正式动作。
  5. 完成46个轴的真实零位和方向标定，并做断线、掉电、整机带线测试，再填实测标定文件和五项验证字段。没有做的项目保持false，不能为了让软件连接就改为true。

零位和方向怎样取得

先在未连接长线之前，把单关节固定在明确的机械参考角度。用量角器/数字角度尺和查看器中的两个刚体基准面确认参考角 θ₀，记录14位原始读数 a₀；沿定义的正方向再移动一个已知角度（例如15°），确认原始读数增加还是减少。记录该方向 sign=+1 或−1，零位按 zero_deg = a₀×360/16384 − sign×θ₀ 计算并折回0–360°。不要把所有零位直接填成0。

多轴机构必须锁住其他轴，分别确认P、C01、C02、D；commissioning/neutral_raw_reference.json 是CAD参考，不是实测值。用第二、第三个已知角度检查线性与方向；物理磁铁安装误差、打印间隙及磁场偏差需要另外记录，不能通过“调零后看起来对”就宣称精度达标。

软硬件衔接流程及命令模板保存于统一包；当前已测试的是合成PDG15数据经过生产桥接器到实际UE插件的流程，尚未声称真实无线链路、传感器或USB实物采集通过。

一次性验证清单

不需要在每一步停下来重新买一批零件。同批零件先完成下面的分项，再装成整机。出现卡住或明显松脱时暂停该部位，记录事实，不以“理论上能用”覆盖失败。

步骤具体动作要留下什么
1. 到货与尺寸按数量点件。拍照记录材料、轴肩长度、垫圈通孔、碟簧高度；打印件检查支撑残留、翘曲与槽口。照片、尺寸、件号、材料和打印服务商参数。
2. 空载装配先每类机构装一个，再把同批其余件装完。每个螺母正向保持、轴肩完整啮合，全部新活动轴缓慢走范围。能否按顺序装入；相邻件是否擦碰；是否需要异常外力。
3. 摆姿与保持把某轴水平放置，在已知垂直力臂r处用拉力计缓慢拉；记录开始动与持续动的力F，扭矩≈F×r。例：0.10m力臂×2N≈0.20N·m，还要计入下游自重。起动力、持续力、正反向差异；1分钟/10分钟/1小时/24小时角度变化。
4. 疲劳初筛每类新模块先做100次慢速正反摆动，检查开裂、螺母槽变形、磨屑和松弛。100次只是初筛，不是寿命定型。前后保持力和手感、是否需要重新调紧。
5. 完整骨架前举、上举、侧举、坐姿、下蹲、翻掌、弯腰转身。人工缓慢移动；非相邻肢体接触可调整姿势，相邻机构干涉必须记录为设计问题。每个需要手托的部位、实际可达范围、碰撞件号与姿态。
6. 带线与供电关节走两端及多轴组合姿势；检查线环、不夹线、不拉FFC。每条链测最远板的供电、冷启动和持续工作温升，示波器看SPI。最小/最大电压、供电电流、温度、信号波形或装配厂测试报告。
7. 标定与采集逐轴确认编号/方向/已知角度，所有必需轴有效后才捕捉；断开每支路、至少一个中间节点、重启BODY/G0，验证拒绝旧/缺失/错误数据。标定表、原始诊断日志、UE保存结果与故障拒绝记录。

软件采集的静止窗口、超时和数据完整性检查仍保留，用于阻止读到旧姿势、混合帧或断线数据；它们不是实时动捕的60Hz、8/14ms硬门槛。不能以放宽时序为由把缺失传感器当成有效角度。

允许手托是本项目已接受的使用方式。先记录“放手能否保持”，再记录“手托后能否可靠采集”；只有两者都写清楚，才能判断哪些轴值得进一步优化。
