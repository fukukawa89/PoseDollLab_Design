# O23H — A1 mini / PLA

本包替代 O23G 的 32 件打印工程，对应几何 `538c5c2bb9ba8445058fc95251ed41d3908bbbb6c48ac6ece0d92314f5e09459`。每件一盘，使用 **0.4 mm 喷嘴**。工程已保存摆放方向、PLA 参数、支撑避让及离线切片结果；请直接打开 3MF 保留这些设置。

先试打左大腿 O23H-S19、左前臂 O23H-S18，再试左锁骨内段 S15 与外段 S10、骨盆 S13。与对应关节件试装，检查端面根部、螺丝进入、扎带穿入和摆动余量。

主结构件使用 5 道壁、20% gyroid 填充；小附件按工程单独设置。临时剥离片属于支撑辅助，打印后拆除，不能留在零件上。各件数量见 manifest.json 的 temporary_caps。先从外侧支撑拆起，再处理局部接触点，避免用连接杆作撬杠。

全部 32 件通过原生网格保持、切片修补计数为零、底板范围、孔槽内支撑路径、悬空起始层和临时剥离片间距检查。模型实体闭合，连接杆两端和承力截面另有独立几何检查。实际层间强度、支撑拆除和反复摆动仍需首件确认。

预计全部挤出耗材 1032.7 g，其中支撑 348.7 g；串行估时 115.5 小时。是切片估算，包含支撑与裙边/边缘，不代表整机净重。
