02 / 实验 A

压下去，究竟有多大力？

测的是“压缩力—高度曲线”。先测单片，再测反向叠放的组合；仪器同时记录力和位置。

建议由弹簧厂家 / 检测方完成
剖面示意
0%

锥度与厚度已夸大；进度条只控制动画，不代表真实压缩行程。夹具是原理示意，尚无生产图。

    记住这个摆法

    相邻两片，朝向相反。

    这叫“对合串联”：同一股力穿过每一片，组合能压缩的行程相加。不要把两片同向套在一起，误当成这里的组合。

    仪器需要做什么

    力和位移，都要实际测量。

    检测方提供已校准的压缩测力装置、导向与限位、平行压板，以及适合小行程的位移测量。量程、分辨率和允许行程由检测方与厂家确认。

    螺丝转了几圈、手感有多紧，都不能代替测力。使用台架放置样件，受压时不要用手指扶着碟簧。

    03 / 实验 B

    压住以后，能稳住也能转动吗？

    固定 PEEK 试片，让金属对偶件缓慢转动。这次只测一个接触面，先了解材料配对的表现。

    建议由有摩擦测矩夹具的检测方完成
    原理示意
    0%

    动画不计算实测扭矩或判定合格。实际夹具、材料牌号、表面与加载方法需检测方确认。

      两个力，要分清

      压紧力 N ≠ 转动扭矩 N·m

      压紧力沿轴向把两面贴在一起。扭矩让金属件绕中心转动。“起动扭矩”是它刚开始转动时需要的扭矩。

      每个预紧设置，都要重复

      顺时针 3 次 + 逆时针 3 次

      在数个实测法向力下重复，并进行 60 秒加载停留。夹具空载阻力要另测、记录和一致处理；不能把夹具的阻力算成材料效果。

      05 / 收好这些，再判断下一步

      拿到曲线和原始记录，才算测过。

      让检测方交付原始仪器文件，并说明测试条件。只有“合格”两个字，无法用来改关节设计。

      向检测方要回这 5 项

      1. 样件与材料身份

        编号、实测尺寸、照片、材料批次；金属牌号、表面加工与温度。

      2. 仪器与装夹说明

        校准编号、量程、分辨率、不确定度、夹具照片，以及空载阻力如何处理。

      3. 碟簧加载 / 卸载原始曲线

        单片及组合的力（N）与高度 / 位移（mm）；保留组合编号、朝向、重复记录。

      4. 摩擦与停留记录

        每个设置的实际法向力（N）、单面起动扭矩（N·m）、方向、加载停留扭矩、实际时长（s）和角度变化（°）。

      5. 可追溯的原始文件

        仪器导出文件、测试日期与操作人。JSON 模板可由我们后续整理，不要求你先学会写代码。
