# Rev O7 小样台架任务书

当前先制作材料试片并测碟簧，不建议制作整个人偶或直接按 LP6 总装 STEP 下单。LP6 是研究装配，生产螺纹、公差、紧固件强度、工具配合和受载变形尚未定型。用户尚无硬件，本目录没有实测结果。

## 首批测试件

| 项目 | 建议首批数量 | 要解决的问题 |
|---|---:|---|
| 锐尔立 B 系列 8×4.2×0.3 mm 碟簧 | 至少 6 片，组成 3 对 | 两片对合串联的实际力—高度曲线与组间差异 |
| 锐尔立 A 系列 8×4.2×0.4 mm 碟簧 | 至少 12 片，组成 3 组四串 | M4 当前组合的实际曲线，确定锁骨轴是否有足够保持力 |
| LP6 接触尺寸的未填充 PEEK 试片 | 至少 3 片，接触区 ID12 / OD28 / 厚0.6 mm | 大接触环的静摩擦、低速起动与停留变化 |
| M4 接触尺寸的未填充 PEEK 试片 | 至少 3 片，接触区 ID5.2 / OD14.8 / 厚0.4 mm | 小接触环能否覆盖约0.304 N·m 的双面保持预算 |
| 两种尺寸金属对偶试片 | 每种至少 1 件 | 使用可追溯牌号和表面加工；其结果只适用于该材料配对 |

[试片 STEP 与尺寸表](coupons/) 包含四个研究实体。外耳用于试验夹具在摩擦区外固定塑料片；金属件安装孔用于实验室夹具。**这里没有完整的测力/测矩夹具设计**，需要加工方或实验室确认装夹、实际尺寸、平面度、金属牌号和表面工艺后再加工。当前关节 CAD 的 `steel` 只是密度分类，不代表已经选定生产钢号。

锐尔立 B8 的目录点为118 N、自由高0.55 mm；目录 Ht 显示0.36 mm，模型使用由75%锥高压缩计算的0.3625 mm。三组理想并联才得到354 N。它不是最大力，也不是已校准的整关节预紧力。[锐尔立官方目录](https://www.raleigh-spring.cn/discspring/)

PEEK 先作为可测的候选。原厂页面给出的摩擦系数来自特定 ASTM 条件，不能直接代入本关节。[Ensinger 原厂材料数据](https://www.ensingerplastics.com/en-us/shapes/peek-tecapeek-natural)

## 台架 A：弹簧曲线

1. 给每片弹簧和每组组合编号，测实际厚度、自由高度、内外径，记录批次与方向。
2. 使用经过校准、适合该力级的压缩测力装置。先测单片，再测对合组合，记录加载和卸载曲线以及重复后的变化。
3. 工作行程依据实际锥高和厂家允许范围确定。**不得仅按模型里的固定高度或螺纹转数推定安全压缩量。** O7 向下取整只约束名义补偿，不是硬件机械限位。
4. 记录组合在预期工作附近的力、回差和组间偏差。三组高度相同不等于三组力相同；这些数据用于后续压力板、导向与紧固件计算。

原始记录使用 `spring_curve_template.json`，保留仪器导出文件。该模板没有填入目录点冒充测量值。

## 台架 B：单面摩擦试片

实验室用校准夹具固定外耳、控制真实法向力，测单面起动扭矩。先测并记录夹具自身阻力；金属对偶牌号、表面加工、塑料批次、温度和实际尺寸必须随记录保存。

在数个真实预紧力下，每个方向至少重复3次，记录起动扭矩和60秒加载停留后的角度变化。可先从低载荷开始，再依据夹具、材料和已测弹簧范围增加。测量值使用 N、N·m、秒、度，不能把单面测量当作双面实测。

`plan.json` 由当前逐件重心载荷报告生成：LP6 最苛刻悬空臂保持预算约0.463 N·m，M4 约0.304 N·m。60 mm 手持力臂、20 N 操作力和0.3°停留漂移仅为**暂定的台架筛选线**，不是用户已确认的最终手感/精度标准。抬起手臂的力包含重力与摩擦。

同一预紧设置中法向力实测范围不得超过均值的5%，才能作为同组初筛；仍须保留原始数据。重复次数不是寿命试验。两面等效推算通过后，也只能进入单关节测试。

## 数据入口

填写 `measurement_template.json` 中的 `samples`，每条记录使用唯一 `sample_id`，保留相对路径和仪器日志 SHA256。脚本会拒绝合成/目录数据、缺少批次/校准编号、非法数值、重复记录、路径越界、日志被改写及不匹配的计划哈希。

在设计仓库根目录执行：

```powershell
.venv/Scripts/python.exe -X utf8 scripts/analyze_revo7_bench.py --plan Hardware/PoseDoll44/bench/revO7/plan.json --data Hardware/PoseDoll44/bench/revO7/measurement_template.json --out Hardware/PoseDoll44/verification/revO7/runs/o7_20260924_r1/bench_measured.json
```

空模板返回 `AWAITING_HARDWARE`。软件测试用例全部是合成数据，不是实测。即使录入结果满足初筛，脚本也不会设置整关节合格或制造放行；文件哈希只能证明记录未变，不能证明实验真实性。

## 测完以后再做什么

用实测静摩擦范围和弹簧曲线确定各轴预紧窗口。如果能同时保持姿态和轻松调整，再完成单关节生产图、力路/螺纹/螺钉强度及限位，然后做受载滑动、三组力不均、正反向加载、轴承基准变化与反复摆姿测试。再据此设计肩锁骨共同支架、完整 PCBA、线束和全身联合动作。

背部中央采集方案另需 AS5048 链路的实际波形、断链/重放识别和峰值供电验证。48×48×12 mm 是已检查的空盒空间目标，尚无相应的中央 PCBA。O6 的 DC1 仍是隔离实验，不能据此改成生产采集架构。
