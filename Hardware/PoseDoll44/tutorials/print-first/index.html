打印从这里开始

先用 PLA-CF 做材料候选

ToddlerBot 的本地 3MF 多数对象指定了 PLA-CF。我们采用它作为首轮候选；普通 PLA 也可以先做低载装配练习，但结果需按材料分开记录。

  1. 选择适合耗材的打印机配置；PLA-CF 使用厂家认可的耐磨喷嘴。
  2. 小样建议从 0.2 mm 层高、6 道外壁开始。小样采用 100% 填充以固定试验变量。
  3. 查看切片预览，清理支撑，测量孔径、垫圈厚度及摩擦面平整度。
  4. 用真实零件试装，能顺畅装配后再逐步加载。

小样的 100% 填充是本项目的试验选择。ToddlerBot 文件的默认填充是25%，部分对象另有覆盖；不能将其设置直接视作我们关节的强度证明。

不是只测螺丝孔

测试真正要回答的问题

  1. 放手能否保持？初始单摩擦点目标约0.20 N·m；100 mm 力臂约对应200 g挂重，需计入长臂自重。
  2. 摆动是否顺畅？记录开始转动和持续转动的力，正反方向分别测量。
  3. 夹紧后会不会慢慢变形？记录1分钟、10分钟、1小时，并加做24小时停留。
  4. 底座自己有没有动？分别观察底座和长臂，避免将底座挠曲误记为摩擦片打滑。

目录中的210 N不是实测夹紧力，也不是需要悬挂的重量。新摩擦材料、表面粗糙度和打印方向均需实测。
