# PoseDoll O17：USB 直连的一体件简化版

O17 是在已保存的 O16 上完成的数字设计候选。一个实体人偶，静态摆姿采集，接受 USB 连线，不依赖摄像头。保留 O16 的 46 路实测、41 个语义旋转自由度和全部关节中心；本轮重点是减少零件与重复装配。未宣称整机实物或 UE 端到端验收通过。

## 已保存的 O16

- 本地 Git 提交：`26255df`；标签：`posedoll-o16-saved-20260930`。
- O16 目录和原设计包保持不变。该包 SHA-256：`b4944bcba95b2ab10523fd785509abc652174c75843798b3c82d85f966861096`。
- O16 为 273 件、214 种打印件，仍可独立打开、核验和复建。保存不代表升级为制造放行版本。

## 实际减掉了什么

| 项目 | O16 | O17 | 说明 |
|---|---:|---:|---|
| 实体人偶 | 1 | 1 | 同一硬件供不同 UE 角色适配 |
| 单套打印件 | 273 | **202** | 减少 71 件，约 26.0%，包含保留的焊接间距治具 |
| 打印件种类 | 214 | **124** | 六种新打印件替换合并件和两个改动骨架 |
| 原始测量通道 | 46 | **46** | 没有删除关节动作或用估计值代替测量 |
| 语义旋转自由度 | 41 | **41** | 关节中心、骨架关系、编码器名义位置保持 |
| XIAO 主控 | 2 | **1** | 人偶直接接电脑，无 G0 网关 |
| 电池、射频天线 | 1 块、2 副 | **0、0** | 改为有线数据和桌面供电 |
| 附件螺钉 / 螺母 | — | **各少 8 个** | 来自电池盖和 G0；关节预紧紧固件保留 |

打印件减少的对应关系：34 组「传感板托 + 板夹」变为 34 件一体托夹；34 组「磁铁座 + 磁铁盖」变为 34 件一体座盖；删除电池盖和 G0 两件外壳。骨盆去除电池盒，胸部增加 USB 开口与扎带槽，但两处骨架仍各是一件。

`N001` 一体托夹 28 件，`N002` 一体托夹 6 件；`N003` 紧凑磁铁座盖 18 件，`N004` 铰链磁铁座盖 16 件；`N005` 骨盆骨架 1 件，`N006` 胸部骨架 1 件。其余 P 编号是逐文件校验保留的 O16 零件。以 `PRINT_UNIVERSAL.csv` 为最终数量依据，STL 和 3MF 是同一件的两种格式。

## 为什么这样简化不减少姿态测量

需要测量的是相邻刚体的实际相对转动。安装座、盖板和螺钉本身不增加姿态信息。因此先合并没有相对运动的零件，保留传感器和关节运动轴。

O17 的 raw 顺序、正向运动学变换、固定骨段与标记、角度诊断范围均与 O16 相同。每个新件仍随原来的刚体运动，没有把两个不同运动部件粘成一个刚体。输出仍使用矩阵 / 四元数，不能把多轴机构的内部编码器角度直接当作角色的单个欧拉角。

头颈与髋部改为三轴、46 路减至 43 路，仅保留为后续研究方向，**不计入本次成果**。还没有针对完整关节任务验证新机构的活动范围和实体避碰。肩部的大范围运动尤其不宜直接删除冗余轴。

## 一体传感板托夹

保留原有底座、可拆接口、定位键和 M3 螺钉，先把 PCB 滑入独立托夹，再装回人偶。传感板的名义位置与原来一致。拆下托夹后，仍能接近磁铁和关节预紧机构。

开口朝托夹局部 +Y 方向。右侧留下约 9 mm 长、0.8 mm 厚、0.8 mm 宽的弹片；抬起的前端阻止 PCB 滑出。取板时手动释放弹片，不能拉着 FFC 硬拽。PCB 装好后才连接 FFC。

小挠度梁估算：释放行程 1.2 mm 时，表面应变约 1.78%。这是几何估算，**不是 PETG 强度或寿命保证**；模型中的释放通道检查将弹片从干涉体中移除，也不是形变仿真。需要试打印验证实际释放行程、断层、蠕变和反复拆装。若卡扣不可靠，保留 O16 可拆托夹，不能用胶封住 PCB 或省略定位。

## 一体磁铁座盖

采用两种参数化座盖，沿用原来的径向尺寸、安装台阶、两个 M2 孔和磁铁名义位置。先在拆下的零件中侧向装入磁铁，再安装到关节上。侧向通道斜着避开大部分螺钉支承面；装上原 M2 螺钉后，螺钉头阻止磁铁沿该通道退出。检查得到的最小螺钉支承面积保留比例约 69.6%，不等于已经验证夹紧强度。

**圆形磁铁必须可靠传递转角。** 螺钉防脱不能保证磁铁不在圆孔里转动。本版在磁铁侧壁与座的间隙使用少量非导电粘接剂，底面保持就位，按胶的厂家说明固化；禁止让胶进入传感器间隙或螺孔。先做磁铁标记、读数和反复摆动对照试验。固化后的「磁铁 + 一体座」作为可更换总成；需要换磁铁时替换总成，不承诺可以无损取出粘好的磁铁。

新座盖由原始参数重建，避免将旧网格的共面接缝直接焊合造成非流形边。与旧三角网格存在极小数值差异，已写入验证报告。不能把它表述成数学上毫无容差的逐点子集证明。

## USB 数据与供电

使用一个 XIAO ESP32S3，直接通过 USB Serial/JTAG 与电脑通信，无 ESP-NOW、配对 MAC 或 G0。固件已单独编译，使用新的 `P17R/1` 协议头；不能把 O16 固件或旧协议接收器当作 O17 即插即用的软件。

本版采用**两路有线连接**：电脑 USB 给主控供电并传输数据；独立稳压 5V USB 电源经 J7 给传感器降压电路供电。两个正电源不相连，电路共地。XIAO 官方资料列出的 Type-C 输入为 5V，详见 [Seeed 官方说明](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)。

原 C1 裸板可保留，装配变体称为 **C1-U**：**D1 不装**，BOM 与贴片坐标已更新。已装过的旧板需拆掉 D1 后再连接。D1 原本会把外部 5V 送到主控的 USB 电源节点，直接双电源连接不符合本版接线。

选用稳压 5V、额定至少 2A 的桌面电源，作为工程余量目标，并非已测得整机功耗。保留现有 3.3V 降压器及六路保护，不从 XIAO 的 3.3V 引脚给所有传感器供电。不要使用输出 9V/12V 的 PD 触发线。采购单包含 USB 数据线、5V 电源线、扎带和粘接剂，不再购买人偶电池或 G0。

胸部控制盒上沿新增 USB 开口及扎带槽。实际插头的横截面须小于所给包络并按实物试装；线缆在外壳处做应力释放，在人偶后方留松弛回环。新 USB 软线的完整运动包络、拉力与弯折寿命尚未验证。

## 数据链的正确性

`46 个编码器 → 六条原 SPI 链 → 单一主控 → USB → 原始记录 → 标定 → 实体姿态 → UE 角色适配`。

每次请求含独立采集标识，设备身份与启动标识固定在一轮采集中。扫描时间上限 60 ms，名义间隔 100 ms；完整稳定窗口至少 500 ms。坏包、缺轴、磁场诊断异常、重放、超时或混合设备不能转成零角度。

USB 参考工具保存原始字节、解码帧和标定。逐通道时间采用整次顺序扫描的保守最早时间界，并单独保留起止界；不声称 46 路同时采样。主机用发送请求之前的时间建立保守年龄上界，避免把 USB 缓冲里的旧数据当成新数据。

提供的是离线验证与采集参考；**未运行新的 Manny / Quinn UE 端到端验收**。角色骨长仍由目标角色保持；根部位移 / 整体旋转、手指不测。目标的多段脊柱、颈部和辅助扭转骨仍须区分实测与派生。接触、脚底、穿模和动作修饰留给 UE 后期。

## 已知整机干涉

本轮直接复查确认：O16 中立姿势的左前臂连接架与骨盆架重叠约 1895.94 mm³，O17仍保留这一问题。24个工况（23个保存姿势加装配姿势）的检查只比较改动件相关的碰撞增量，并没有消除旧干涉。图中的姿势不能当作可摆到的实物姿势；`REGRESSION_PASS_WITH_INHERITED_OVERLAPS` 不能读作整机零碰撞。

因此本版交付为**简化小样候选**：数量、可制造网格和测量模型已经具体化，但全机干涉仍是整机制造前必须解决的问题。

## 先做的小样与放行条件

1. 先打印 N001、N002、N003、N004 各一件，使用真实 PCB、FFC、磁铁和标准螺钉试装。避免一次打印整套 202 件。
2. 检查托夹能定位 PCB、连接器不受力、弹片能够操作和反复拆装，磁铁总成不轴向窜动或相对转动。保留零位、误差、回差和重复性记录。
3. D1 不装的 C1-U 先限流上电，核对 J7 极性和两路电源断开时的反灌电流、传感器末端电压和温升；再做 USB 断连、拔掉一轴、故障标志和设备重启测试。
4. 验证单关节、相邻组合和实际带线摆姿，检查保持力、打印蠕变和关节邻近干涉。离散数字回归不能替代全工作域或实物验证。
5. 用独立量具验证实体，再分别在 Manny / Quinn 最终求值骨架与可编辑关键帧上验收基础转换。

本轮的实测空白须保留为空白，不得从数字样例填出「通过」。`verification/` 记录几何、服务通道、21 项 Python 测试、C 协议与会话测试、固件编译和浏览器检查；报告中的 `physical_tested` 与 `ue_end_to_end_tested` 均应保持 false。

## 复建与核验

仓库中使用现有 CAD Python 环境，依次运行 `cad/revO17/geometry.py`、`export.py`、`verify_geometry.py`、`test_device.py`、`test_usb.py`，最后运行 `package.py`。这些脚本只写 O17 路径。CAD 复建依赖仓库中冻结的 O15/O16 输入；交付包中的 STL / 3MF 和查看页可以单独使用。

固件源代码在 `Firmware/PoseDollFullBody/revO17/`。`build.ps1` 只编译，不刷写。`test_native.cmd` 运行本机 C 校验。禁用射频后，启动标识使用临时启用的内部熵源生成；参见 [Espressif ESP32-S3 随机数说明](https://docs.espressif.com/projects/esp-idf/zh_CN/v6.1/esp32s3/api-reference/system/random.html)。
