# P21R/1：O21 USB 静态捕捉

248 字节固定长度，小端整数，魔数 P21R，版本 1；SSI 在线上传输的 MSB-first 位序与 USB 小端装箱分开处理。禁止使用 P17R/1 解码器解释本包。

| 偏移 | 字节 | 定义 |
|---:|---:|---|
| 0 | 4 | ASCII P21R |
| 4 | 1 | 1 |
| 5 | 1 | PROBE=0、HELLO=1、REQUEST=2、ACCEPTED=3、SCAN=4、CANCEL=5、STOP=6、ERROR=7 |
| 6 | 2 | 保留，零 |
| 8/16/24 | 各8 | device、transport_boot、body_boot |
| 32 | 16 | 本次 capture ID |
| 48/52 | 各4 | scan sequence、token |
| 56/64/72 | 各8 | request/start/end 微秒时间 |
| 80 | 6 | 固定 14,16,16,0,0,0 |
| 86 | 2 | 保留，零 |
| 88 | 8 | valid_mask，低46位 |
| 96 | 138 | 46 个 uint24 原始 SSI 字，USB 中小端；顺序按 raw_order |
| 234 | 2 | 保留，零 |
| 236 | 8 | idle_high_mask，低46位 |
| 244 | 4 | 对前244字节的 CRC32/ISO-HDLC，与 zlib.crc32 一致 |

SSI 字高14位为角度，中4位为磁场/Push/失锁状态，低6位 CRC。CRC 多项式 x6+x+1，18 位数据 MSB-first，当前实现 init=0、xorout=0；与独立长除法和公开项目惯例一致，仍需实物已知角度/时序确认。所有非零状态在本版静态采集中拒绝，并原样保留。

SCAN 解码同时重算每路 CRC/状态/空闲检查，与 valid_mask 交叉核对。只允许完整46路、同设备/启动/捕捉ID、递增 token 和连续扫描序号的窗口。缺失、故障、超时不插值、不补零；全零是可能的合法角度，所以必须结合 idle_high 及物理通道电测，而不是仅检查数值。

扫描器初始等待100ms，再使能接口；每槽位片选高/CLK低时选择DO，静置20µs检查空闲高，再片选低逐位发时钟。每半周期至少20µs，采样在高电平等待后、下降沿之前；硬件时序和空闲检查属于待验证候选。25kHz 是候选上限附近的纯等待时钟，GPIO 调用和任务调度会延长。全轮超过60ms拒绝，正常轮间隔100ms，稳定窗口500ms。

三个数据 GPIO 依次读取，相隔少量软件执行时间；保守时间戳使用全轮 [start,end]，不能宣称同时采样或硬实时延迟已实测。只面向摆稳后采集，不承诺连续高速动作捕捉。

原始 USB 包和完整标定写入记录；可选误差表的修正样本单独保存。hardware_capture_eligible 只有在 MEASURED 标定与所有指定实物检查均为 true 后才为真，SYNTHETIC 测试不会获准作为实物证据。模板保留为 UNCALIBRATED。
