# O19 腿部连接杆对齐优化

O18 已保存为 `08e8f8b`，标签 `posedoll-o18-prototype-20260930`。O18 包含342项带哈希文件，设计包 SHA-256 为 `65e74ea2ee1191e7b7bc30909e66c15424c8b2c1608889a85eba3c7dff7b203d`。O19 独立保存，不覆盖 O11、O16、O17 或 O18。

## 本轮决定

保留一套 USB 测姿人偶，沿用既有 Quinn 比例的实体参考，Manny 与 Quinn 为软件适配目标。仍为46路原始测量、25个物理模块、41个语义旋转自由度、188件打印件和117种打印件。中立数字实体高度492.140 mm。

本轮只替换四件腿部连接架的自由杆段，不增加摩擦副、锁紧机构、传感器或其他零件。所有有效关节中心、角度组成、骨段坐标、零位定义、五金净数量和USB协议保持O18状态。原采集软件与固件继续使用。

## “整机干涉”具体是什么

整机干涉是两个真实结构件、五金或电子件在某个姿态下占用了同一片空间，实物会相碰，从而无法继续摆到目标角度。它与目标角色皮肤、衣服或道具的穿模是两个不同的问题。

可复现例子：O18中立姿势的 `frame/pelvis` 与 `frame/forearm_l` 相交约1895.939 mm³，即1.896 cm³。这个数是相交体积，不是间隙、距离或穿透深度。O19未修改这两件，此处问题仍在。新网页的“整机干涉示例”用两件实际CAD和其布尔交集高亮展示该位置。

O18此前的24案例报告只检查13件变化连接架与其他零件的相交；本轮报告只检查4件新腿杆与整机其他几何。两者都不能称为所有零件、所有角度的整机通过结论。侧躺、俯卧等空角度案例没有地面、支撑和整体空间变换，不能据此声称卧姿避碰通过。

## 腿部改动与剩余偏差

承力杆外形中心线不等于有效转轴。只有转轴位置、父子变换和骨段长度决定刚体运动学；因此将杆画直不会自动修正被外移的髋轴心。

|替换件|O18同高度的杆中心距参考骨线|O19中间直段距参考骨线|该直段长度|
|---|---:|---:|---:|
|L001 左大腿连接架|18.745 mm|0 mm|25 mm|
|L002 右大腿连接架|21.514 mm|6 mm，向前|25 mm|
|L003 左小腿连接架|1.291 mm|0 mm|29 mm|
|L004 右小腿连接架|1.291 mm|0 mm|29 mm|

这是中间直段的比较，不是宣称整根连接杆或整条腿与UE完全重合。两端仍保留必要转接。右大腿若也完全归零，会新增手臂后摆时的手部碰撞，因此保留向前6mm偏移；大腿顶部转接范围也经过避碰调整。主杆直径保持10mm，端部的原关节几何保留；数字布尔检查端部差异小于1e-4 mm³。

髋中心仍各向外16mm；左右有效髋距约90.987mm，UE参考约58.987mm。膝、踝的中立有效中心仍与既有UE参考位置吻合。腿部参考骨线按既有480mm Quinn参考缩放计算，492.140mm为包含实体零件的最终中立包络高度，两者不是同一尺寸定义。

## 为什么没有直接把髋中心搬回去

本轮试算了零偏移的多组四轴髋机构安装方向、相位和冗余轴分解，以及8/12/14mm等较小偏移。部分零偏移方案在站立、装配位和坐姿无髋部碰撞，但深蹲或外展发生实体相交。例如相位90°、倾转60°、零偏移的试案，深蹲出现髋环相交；外展出现两侧传感板托夹相交。该试案被拒绝，没有混入O19正式零件。

这些是有限搜索结果，不是数学上证明“无法对齐”。继续消除16mm髋偏移需要重新解决髋机构的空间包络，例如改变髋模块布置或整体参考尺度，并重做相邻模块与走线检查。当前不以缩小姿态要求、增加保持力零件或隐藏碰撞来换取对齐结论。

试算证据保留在 `hip_mount_candidates.json`、`hip_mount_refined.json`、`hip_mount_final_search.json`、`hip_mount_compromise.json` 和 `hip_branch_search.json`。另保留初次直杆试案产生新碰撞的记录，便于区分已放弃试案与正式四件替换件。

## 查看器修正

蓝线：独立UE解剖参考模型的对应关节中心连线，采用Quinn比例。橙线：实体模块实际有效转轴中心连线，按当前示例姿态求值。二者都来自各自的运动学数据，不从连接杆外形推测。

旧网页的参考线连接的是实体骨段坐标原点。中立补偿可能使它们看上去与UE一致，却掩盖实际髋转轴偏移。O19改为独立绘制两套轴心并用十字标记端点。线表示本设备支持的关节拓扑，不是UE全部蒙皮辅助骨。

“腿部对照”默认左O18、右O19。可切正面/侧面、关闭金属和电子件、单独显示连接架和两套参考线。“整机干涉示例”的红色为实际布尔交集的透视高亮，便于看到实体内部的相交区域。

## 已完成的验证

- 四件新杆各为一个闭合实体。STL与3MF已重新读入校验；非流形边为0，格式间体积差小于0.001mm³。
- 与O18比较24个姿态案例（含重复中立角度的标签），四件新腿杆对所有保留几何没有新增或增大的相交体积，比较容差0.001mm³。继承干涉如实保留。
- 对坐下、下蹲、外展、跪姿、手臂后摆补查43个中间样本，语义角步长不超过10°，同样没有新增或增大的相交。四轴冗余分解可能跨分支，这不是连续编码器路径或连续扫掠的证明。
- 采集/USB共21项原有测试在O19配置下通过，包括46通道异常拒收、坐标/四元数计算、CAD姿态回归和数据包检查。
- 骨架变换、原始通道、标定参考角、USB协议、五金净数量与O18一致；没有把O11摩擦报告当作传感器标定。
- 浏览器检查、冻结包哈希与ZIP一致性记录随交付包提供。

软线束的最终绕行与绑点仍随新杆件实装核对；本次碰撞检查包含已有硬件、板件和刚性尾线模型，不含未建模的软线束连续包络。连接器端点和原链路/裁线数据未改变，不能因此宣称新的绑线方式已经实测。
