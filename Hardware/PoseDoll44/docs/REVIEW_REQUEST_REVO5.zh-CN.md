## 机械反例和决策

试验布局中，锁骨关节与 N2 实体的求交量：Manny **999.63 mm³**、Quinn **987.82 mm³**；肩关节与近端板厂商天线空域的求交量分别为 **3340.49 / 5393.94 mm³**。这是这组定位的真实 BRep 反例，不是包围盒体积相加，也不能推出所有 480 mm 方案都无解。

A/C 共享这些冲突，故 C 暂缓定型。J50 草案最长约 305 mm；在假设 60°C、线阻 +10%、200 mA 时，C 的 Manny 草案末端计算约 3.036 V，未达到另设的 50 mV 储备。实际最大线长与电流未冻结，不能据此宣称原 3.3 V 供电已经合格。

详见 [机械、线束与局限](O5_MECHANICAL_AND_WIRE.zh-CN.md)、[固件协议](../../../Firmware/PoseDollFullBody/revO5/README.zh-CN.md)、[桥接入口](../../../Tools/PoseDollHardwareBridge/README_O5.zh-CN.md)。建议下轮审查优先决定具体的肩部输出/叉架与 N2/近端板重排，随后在同一可装配路径内比较 A/C；目前继续缩小孤立 C 板没有关闭主阻塞。
