# O24A 手臂动画教程

[打开教程](preview/tutorial.html)。本机预览地址：<http://127.0.0.1:8774/preview/tutorial.html>。也可以双击 `StartTutorial.cmd`，直接打开离线网页；须保留整个 `preview/` 目录。页面不依赖 CDN、网络模型或外部字体。

建议从「肘关节」开始。青绿色是当前轴的固定侧，金色是转动侧，紫色是旋转轴，粉色是 UE 骨线。前一级轴转动时，后续模块会跟着一起运动；“固定”指相对于当前演示的轴固定。

## 三种模式

- **看旋转**：选一根轴，观察轴承座、轴和下一段手臂如何相对运动。角度显示在播放按钮旁。教学角度采用较容易观察的范围，不代表人体所有动作或硬件极限。
- **拆开看**：拉开零件或整臂模块的间距，虚线连接原始装配位置。点击标签，可查看对应真实实体的作用。
- **装回去**：分六步回到模型的名义装配位置。单关节依次展示支架、轴承、转动件、摩擦与压紧件、磁铁、传感板；整臂依次展示肩带、肩与上臂、肘、前臂、腕和手掌。

播放、暂停、重播、0.5× 慢放和时间滑块均可用。「上一步 / 下一步」在装配模式中按六步跳转。拖动模型调整视角，滚轮缩放；「复位」恢复当前章节的取景。手机窄屏下说明文字位于模型下方；章节条可以横向滚动。系统启用减少动画时，初次载入保持暂停。

## 六章的观察重点

| 章节 | 主要问题 |
|---|---|
| 肘关节 | 两侧叉架如何支撑同一根横轴，肘转子如何带动前臂 |
| 前臂旋转 | 中空轴如何沿 E—W 骨线转动，为什么腕中心不会偏心画圈 |
| 手腕 | 两对短轴如何连接输入叉、十字块和输出叉，避免实体轴互相穿透 |
| 肩关节 | 前举、外展与上臂内外旋如何由三级结构串联，三根轴线如何经过 S |
| 锁骨与肩带 | 两根轴线如何经过 C，肩点如何随锁骨移动 |
| 整臂总览 | 九根轴与六个模块如何组成完整左臂 |

## 教程与制造说明的区别

教程直接使用现有 O24A 的 124 个实体及原始骨架参数。本次未改变 CAD 几何、活动范围配置、原有 Blender 文件或制造成熟度。零件展开使用额外的展示平移，完成装配时这些平移归零；旋转模式使用原模型的层级运动学，并保留前臂中立位的 −90° 时钟角。

展开距离、移入路径及六步分组是教学安排，**不是经过可装配性验证的实际施工顺序**。零件之间的防转连接、磁铁座、轴向锁固、预紧闭合路径、完整线束及工具空间尚未定稿；动画没有替这些缺失项补造结构。轴承简化为环形实体，没有分别显示内圈、外圈和滚珠。腕部尺偏 / 桡偏轴的轴承外圈跟随输出叉转动，不能把画面中的整个轴承环理解成一个刚体内外圈。

肩外展接近 90° 的万向架奇异位形仍然存在。教程外展示范到 80°，并在章节中明确说明该限制。完整人偶未制成，560 mm 是对应 UE 角色的中立站姿参考高度。
