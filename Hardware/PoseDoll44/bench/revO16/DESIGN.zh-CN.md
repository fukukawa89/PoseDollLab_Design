# O16：单一通用静态测姿人偶设计

日期：2026-09-30。型号：**O16 Universal**。数量：**1 台**。状态：**数字设计候选，不是整机制造放行**。

本版按《优化人偶设计方案》最后两轮讨论收敛：可靠测量实体自身的姿态，确定性地转换给 UE，动画师在 UE 中处理接触、穿模与表演。对话最初的“双体型、逐骨几何重合、ExactFK 严格复刻”已被后续讨论修改，不能再作为本版约束。

## 1. 已冻结的需求

| 项目 | O16 的要求 |
|---|---|
| 实体数量 | 一个硬件型号、一套打印数量、一套通道与标定；不因切换 Manny / Quinn 更换身体零件 |
| 高度 | 标准直立姿态足底到最高实体点 ≤600 mm；计入人偶上的头部设备、紧固件与尾线，不含独立桌面网关 |
| 身体结构 | 人体式全身关节、合理比例与可用活动范围；不要求任何角色的骨长、轴心逐一重合 |
| 实体运动 | 相邻机构不得碰撞、夹线、拉紧导线；此项保留为硬性放行条件 |
| 测量 | 所有可动测量轴都必须被采集；零位、方向、回差、重复性、载荷挠曲与静态稳定性可核验 |
| 数据 | 断线、故障、未标定、混合采集、过期、重启、重放不能变为有效测量 |
| UE | 已知参考姿势与坐标关系下的基础转换正确；生成可编辑、可保存重开的关键帧 |
| 不承担的工作 | 自动贴地、接触识别、抓握约束、防穿模、动作美化；不据目标角色接触状态拒绝有效测量 |
| 工作方式 | 摆姿—扶稳—采集—在 UE 安排关键帧与过渡；本轮不增加连续高帧率动捕要求 |

骨盆相对桌面的六自由度、手指没有测量。整体运动与手型由 UE 编辑。没有增加被动测量支撑臂，也没有要求按 UE 每根颈椎、脊柱辅助骨安装独立传感器。

## 2. 机械基线与这次改变的范围

**选用 O15 Quinn 已完成的机械几何作为唯一通用实体。O16 本轮没有重画这些关节、连接架或外壳，也没有把它们整体缩放。** 选择它是为了复用已有数字装配、切片与带设备的检查资料，并消除两套实体的维护与误配。

O16 交付将这套几何固定为 `universal`；Quinn 只出现在来源记录和历史证据中。它不再是“只能驱动 Quinn 的实体”。打印件仍用已有 P 编号，左右件仍有区别，不能镜像替代 PCB 或混装左右零件。

已重新从最终实体网格计算：中立位包络约 **164.0 ×169.0 ×492.14 mm（前后×左右×高）**；张臂装配位高约492.93 mm。网格简化精度为0.03 mm，精确实体检查另见 `generated/revO16/exact_geometry_check.json`，实物尺寸仍待装配测量。

当前约49.2 cm已给60 cm留出约10.8 cm空间；没有理由仅为满足已取消的“UE逐骨重合”目标把它扩大到58 cm。此结论并不说明49.2 cm是理论最小尺寸。

| 部位 | 机构 | 原始传感器数 | 对外解释 |
|---|---|---:|---|
| 腰、胸 | 各一套3轴模块 | 6 | 两处实测相对旋转；目标更多脊柱骨由适配规则派生 |
| 头颈 | 万向节加两端扭转 | 4 | 一处三维相对姿态；不声称逐节颈椎实测 |
| 左右锁骨 | 每侧两个串联铰链 | 4 | 实际轴线不同中心，完整记录其机械偏移 |
| 左右肩 | 每侧四原始角多轴模块 | 8 | 全部四路参与三维姿态重建，不能丢一轴 |
| 左右肘 | 单轴铰链 | 2 | 屈伸 |
| 左右前臂 | 单轴旋转机构 | 2 | 旋前/旋后；不等于逐根 UE twist 骨实测 |
| 左右腕 | 每侧两个串联铰链 | 4 | 屈伸、侧摆，保留实际间距 |
| 左右髋 | 每侧四原始角多轴模块 | 8 | 与肩同类测量原理 |
| 左右膝 | 单轴铰链 | 2 | 屈伸 |
| 左右踝 | 每侧双轴模块 | 4 | 踝屈伸、内外翻 |
| 左右前足 | 每侧单轴铰链 | 2 | 前足屈伸；脚趾不是逐趾测量 |
| **合计** | **25个物理关节模块** | **46** | **41个姿态参数；另有3个固定骨盆兼容槽，固定值不是测量** |

保留FDM打印结构、现成轴肩螺钉、垫圈、碟簧、径向充磁磁铁与编码板。传感器应读到承力输出件的实际转动；磁铁座、轴肩、轴承与输出件滑动会造成测量错误，不能靠软件零位补偿长期掩盖。

本版实体仍保留背部C1控制盒、腰后供电模块及桌面USB网关；没有声称已经完成设备外移或减重。重量约1.67 kg是继承的预算，允许手托，不另加1.2 kg硬门槛。把控制盒移到桌面会改变线长、压降、信号完整性和线束拉力，因此不把尚未重验的外移结构混入本版零件包。

## 3. 单一数据源：实体是什么，就描述什么

`profiles/device_profile.json` 是O16的实体测量模型：

- 一个硬件ID、46路原始通道、25个模块的父子关系。
- 每个模块的固定安装变换、真实旋转次序、输出连接偏移。
- 真实骨盆参考与固定外形标记，不借用某个目标角色的骨长作实体真值。
- 中立原始角只是装配参考，不是46颗传感器的实测电气零位。

坐标为右手系，X前、Y左、Z上，毫米，列向量；四元数为xyzw。进入UE时统一转换单位与坐标，不逐项复制欧拉角。

每一段使用：`T_child = T_parent · T_mount · R_raw(q) · T_output`。肩髋和头的旋转次序为 `Rz(q0) Rx(q1) Ry(q2) Rz(q3)`，腰胸为前三项。踝为 `Ry(-q1) Rx(q0)`。左右镜像安装矩阵可能各自含反射，输出身体旋转必须始终为det=+1；不能直接把反射矩阵转成四元数。

这些偏移描述实体本身，并不是为了宣称与UE几何相同而添加的补偿。运行时直接由原始角生成矩阵/四元数，不需要先反解到旧的41轴欧拉范围。

**测量成功和目标适配成功分开保存。** 假如某个真实姿态无法被旧Control Rig配置表达，原始测量仍可存档，目标转换返回失败或不支持；禁止悄悄裁剪关节角、填零，或把适配失败说成传感器坏了。

`cad/revO16/device.py` 为离线参考实现；它不是已接入串口的生产驱动，也不自动写入UE资产。

## 4. 采集、电路与标定

保留46颗AS5048A小板、一个C1身体采集板、BODY/G0链路及六条链：J1躯干6、J2头部4、J3/J4手臂各10、J5/J6腿部各8。针脚、方向、原始通道顺序见 `profiles/wiring.json` 与 `profiles/channels.csv`。

O15电路与固件作为原样复用件收录。其历史ERC/DRC与构建结果并不等于O16实测通过；本轮没有烧录或操作真实硬件。固件默认MAC不是有效配对，需按原制造资料绑定真实BODY/G0设备。

静态窗口的初始工程目标：至少6次完整扫描、覆盖500 ms；相邻扫描间隔≤120 ms；单次扫描通道时差≤60 ms；单通道年龄≤120 ms；每路角度峰峰值≤0.5°。这是待真实硬件确认的设计预算，不能降低它来掩盖漂移或夹线。

整个窗口必须属于同一个设备、boot、capture；扫描序号严格递增，CRC和传感器状态正常，46路齐全。不把每轴不同时刻的平均数拼成“测到的姿势”；稳定后选最后一个完整扫描作为姿态，保留整个窗口供诊断。

标定记录至少包含实际设备ID、profile哈希、46路零位、符号、装配参考角、证据及日期。每一轴都需独立治具/测角工具验证，不得把CAD的参考角直接填写为已完成标定。

`calibration_INCOMPLETE.json` 默认所有电气零位和方向为空。软件必须拒绝未完成标定。合成样本即使数学有效，也只能标成SYNTHETIC，不能作为实物测量验收。

物理测量验收初始目标：校准后单轴误差≤1°、双向回到同位重复性≤0.5°；典型负载保持10分钟姿态漂移≤1°。精度是设计目标，不是AS5048A分辨率或整机已经达到的指标。记录未参与拟合的留出姿势，并分别报告回差、结构变形、磁偏心、噪声与总误差；多个关节误差累积后不承诺末端毫米精度。

## 5. UE适配职责

```text
46路带状态原始测量 + 标定版本
  → 完整稳定窗口校验
  → 实体数字骨架的相对旋转与实际FK
  → 保存原始测量和校准快照
  → Manny 或 Quinn 的独立目标适配
  → Control Rig求值、可编辑关键帧、保存重开
```

同一份测量可重复转换给不同角色。每个目标必须拥有实际导出的mesh/rig路径、骨骼层级与参考姿态、基变换、控制器映射和资产指纹。保留目标自己的骨长；不要把实体毫米坐标写进目标参考骨架。

局部旋转转换需在明确定义的参考帧中计算：例如约定设备增量为 `D = R_source · R_source0^-1`，令 `C` 把设备父参考帧转换为目标父参考帧，则 `R_target = C · D · C^-1 · R_target0`。有左右反射或父帧差异时先用矩阵统一处理；用实测单轴方向、组合旋转与最终骨骼回读验证，不能只比较发给control的值。

脊柱、颈部与twist辅助骨可按冻结的旋转分配规则派生，权重属于目标配置，不属于硬件profile。Manny已有目标配置可复用其发现结果；Quinn需要单独导出和验证，不能只把Manny JSON中的名称替换一下就宣布支持。

本轮未修改UE插件、未新增Quinn生产适配，也未宣称O16的UE端到端通过。`target_adapter_contract.json` 列出已发现资料与待完成检查。现有O15桥接只在旧语义工作范围内作为兼容路径；它不是完整O16四元数接口。

验收Manny和Quinn时，各自检查中立、左右单轴、正负转动、耦合姿势和多轴奇异位附近，Capture后关闭输入、保存、关闭编辑器、重开、Undo和鼠标改键。逐段方向应符合配置，骨长不应被写成人偶长度。数字适配往返目标误差≤0.1°是拟定门槛；目标接触、衣服穿模、脚离地不作为测量拒绝条件。

## 6. 无干涉仍是未关闭的硬性要求

**O16仍不具备“整个允许工作域连续无相邻干涉”的证明。** 继承O15每体型416步原始路径、689个设备/刚性尾线离散工况的历史结果，只能说明对应样本。O16取消另一体型后不会自动获得新的连续避碰结论。

软件里的单轴上下限不代表各轴任意组合都允许。不能只选一个能避碰的肩髋四角分解，也不能缩小范围后把“抬臂、抱臂、后脑、背后、深屈肘、蹲跪、躯干耦合、抬低头”等原任务删除。

下一次机构放行必须执行以下方法，且所有未证实区域保持UNKNOWN：

1. 从完整实体模型建立相邻与同模块运动件对；包含轴端、螺钉、螺母、板、插头、固定尾线和连接架。只有有证据的轴承/摩擦/装配接触可列为预期接触，不能按整个模块跳过。
2. 对每对结构提取影响相对位置的局部原始轴，不枚举不相关的全身自由度。建立真实允许域以及物理限位方式。
3. 对配置单元中心计算保守几何距离下界d，并用半径与关节角区间求运动上界u。仅在 `d - u > clearance` 时证明整个单元安全；否则递归细分或报告碰撞/UNKNOWN。建议非接触打印运动件的设计余隙目标≥1.0 mm，并另计打印误差、挠曲与线束。
4. 持续路径安全与整个允许域安全分别记录。自由摆动设备必须通过实体限位或几何避让排除不允许区域；采集端提示不能阻止人的手把机构转入碰撞。
5. 柔性导线做真实全范围走线、拉力、夹线和循环弯折验证。固定短尾线网格通过不能代替这一项。

完整数字域证明、带线装配、保持力与电子实测通过之前，这些STL用于候选样机评审和验证，不代表已满足整机制造放行。发现冲突时修改实际零件和实体profile，再重建相关检查；不得用隐藏网格或保持末端位置的算法掩盖机械问题。

## 7. 一台的交付清单

- `PoseDoll_O16_Universal_Design.zip`：单一型号的设计与验证候选包。
- `print_batch/`：**214种文件、273件打印件**，其中包含原有桌面附件/治具；按 `PRINT_UNIVERSAL.csv` 计一次数量。STL与3MF是同一零件的两种格式，不能各打印一遍。
- `procurement.json`：单台净数量与备件分列；46套传感小板/磁铁、1套身体载板、BODY与G0各一块主控。
- `harness/`：一套线束、六条链，不把两套角色线束相加。
- `profiles/`：真实机械树、通道表、未完成标定模板、合成姿态回归夹具。
- `electronics/`、`firmware_source/`：继承的电路制造资料和源代码，历史型号标记保持可追溯。
- 三维查看页：仅一个硬件模型，可选姿势、部位、打印件与分解查看；蓝线为设备参考骨架。
- `historical_o15/`：原装配工艺参考；其旧双体型和旧验证状态不覆盖本版需求。

复建：在仓库根目录运行 `.venv/Scripts/python.exe Hardware/PoseDoll44/cad/revO16/build.py`。验证：运行同目录 `verify_geometry.py`、`test_device.py`，随后运行 `package.py` 打包及 `verify_package.py` 核验；本轮真实结果见 `generated/revO16/`。三维查看器由 `scripts/serve_posedoll_tutorials.py` 现有本地服务提供。

## 8. 实施与验收记录

| 验收项 | 当前证据 | 放行要求 |
|---|---|---|
| 一个硬件型号、一套数量 | O16自动生成与清单复核 | 不含第二体型输出 |
| 数字外包络≤600 mm | 本轮网格/实体尺寸检查 | 实物装好后再次量测 |
| 原始轴到实体姿态 | CAD回归、解析例与故障测试 | 再用独立测量治具核验实物 |
| 相邻关节无干涉 | 继承离散证据，连续域未证明 | 完整域或实体强制限位+可达路径，带线实测 |
| 电气可靠性、保持力、寿命 | 未实测 | 同批样机逐项测量，不填默认PASS |
| Manny基础转换与可编辑保存 | 旧版有历史结果 | O16新接口需重新验收 |
| Quinn基础转换与可编辑保存 | 未完成 | 独立配置与真实UE验收 |
| 接触/防穿模 | 从本阶段范围删除 | 不以此拒绝有效测量 |

建议一次准备同批样机所需资料，先检查肩肘腕链、腰胸头链与带线活动，再装完整人偶；这不要求每一步都重新采购。采集标定、几何避碰与目标适配是不同验收项，任何一项通过都不能替代另一项。
