# O11：家用打印小样的制作与测试

本版把定制铝底座改成两个打印半件，长臂也用家用 FDM 打印。金属件全部按目录规格购买，无需车轴、铣铝、激光切特殊钢片或打印金属。这里先制作的是独立材料小样，完整人偶尚未制造放行。

## 先打开什么

- 图解页面：`../../tutorials/print-first/index.html`，可旋转、拆开并高亮零件。
- `print_beds/bench.3mf`：只含底座两半和长臂，已经按建议方向摆放。单位 mm，没有 G-code、机器配置或实测打印结果。
- `print_beds/*_on_bed.stl`：单个打印件；以 `printed_` 开头的三件用于小样。
- `print_beds/core_fit_only.3mf`：双轴核心的装配研究件，尚不是完整肩部的制作包。
- `measurement_template.json`：空白记录表，所有数值都需要实际测量。

导入 3MF 时选择自己的打印机、喷嘴和耗材。不要执行别人机器的 G-code，也不要把作者的 X1C 机型设置直接搬到其他打印机。

另备现成小台钳或夹具、2 mm和2.5 mm内六角扳手、5.5 mm扳手、游标卡尺、细绳、小挂钩及可称重的砝码/重物。夹具要同时固定两半底座。底座外侧还留有M4通孔，可按固定板厚度选常规螺栓；这些属于外部台架，不包含在15件小样CAD中。

## 推荐的第一批打印

以 **PLA-CF** 为首轮材料候选，参考用户提供的 ToddlerBot 文件。并不是已经验证它能承受本关节全部长期载荷。普通 PLA 也可先做低载试装，不要将不同材料、方向、壁厚的试验结果混在一起。

- 用耗材厂家认可的耐磨喷嘴；本轮起点是0.4 mm喷嘴、0.2 mm层高、6道外壁。
- 小样的三件先用100%填充、5层顶面/5层底面，目的是固定试验变量，避免把填充差异误认为材料差异。此设置由本项目选择，不是 ToddlerBot 的默认25%填充。
- 使用厂家对应机型的温度和速度配置。机器、喷嘴和耗材未经确认，本包没有编造通用 G-code。
- 长臂平放；底座两半按3MF方向让分合面朝打印平台。切片时检查内部螺母/垫圈座的桥接与支撑；支撑必须能够从分合面清除。
- 看逐层预览：载荷面不能只剩稀疏填充，孔边不能出现断线，不能有封死而无法清理的支撑。几何排版已检查，尚未用用户实际机型完成切片或试打。
- 若要制作双轴核心的装配样件，承力环分合面朝平台，叉架横放方向仅作为候选。检查弧面支撑和孔的层间方向。完整核心的承载验证仍独立于这个小样。

不要通过盲目拧紧去挤出孔径公差。打印中心孔名义4.25 mm；实际小孔可能偏小，去毛刺后确认光轴能够转动，必要时用合适手工具修孔并记录最终尺寸。不要磨薄标准垫圈去强行套用旧版尺寸。

## 按这个顺序装

1. 将两个底座半件分开。把内部M3螺母放入六角槽，M3大垫圈放入相邻圆槽。圆垫圈朝向长臂一侧。它们通过打印件的承压台阶承受轴向力。
2. 合上底座，用两颗M3×35螺钉与两颗外侧螺母连接。先检查分合面闭合、内部零件未夹歪，再均匀紧固。
3. 在正面依次放：**M4大垫圈 → 打印长臂 → M4大垫圈 → 两片反向碟簧 → M4普通平垫圈 → 轴肩螺钉**。
4. 让轴肩螺钉拧入内部M3螺母。先消除明显松旷，再逐步调整；不要把拧紧扭矩直接换算为夹紧力。
5. 固定底座，让转轴水平、长臂在竖直面内摆动。先空载移动，确认没有擦碰、卡死、松脱或分合面张开。

两片碟簧反向串联增加可用压缩行程，不会把210 N变成420 N。目录中的210 N对应特定单片高度，是参考点，不是本件实测力或允许悬挂21 kg。

## 测什么，而不是只改孔径

首先检查小样能否在保持姿势的同时仍然容易转动，并观察打印材料在持续夹紧后是否松弛。孔径只影响能否装配，是前置检查。

1. **先低载。** 从小挂重开始，逐级接近约0.20 N·m的单摩擦点筛选目标。100 mm的实际垂直力臂大约对应200 g挂重，但还需加上长臂、挂钩和绳子的自重力矩。这个目标由新载荷预算确定，并非测得的能力。
2. **记录夹紧状态。** 分别研究两片碟簧总高1.10、1.00、0.90 mm的情况；这些是候选试验点。准确测不到时记录“未测得”，不要用拧了几圈替代高度或力。0.80 mm只用于数字极限尺寸检查，不是推荐的试验起点。
3. **保持与漂移。** 正、反向分别记录60、600、3600秒，另做24小时停留。初始漂移筛选值0.3°；测量误差若已经接近或超过它，只能判“测不清”，不能判通过。
4. **分清底座动还是长臂滑。** 给底座和长臂分别设参照线，对固定背景拍照或测位移，记录两者相对变化。100 mm处0.3°约相当于0.52 mm位移，可用于理解所需测量分辨率，不能替代误差核算。
5. **摆动手感。** 测开始转动和匀速转动所需的力，并记录操作位置。不同预紧分别比较；更能保持不代表更好操作。
6. **松动与磨损。** 给螺钉头做见证标记；多次往返后复查螺母、表面、孔径、夹紧高度和保持能力。出现裂纹、明显变形或突然滑脱即结束该样品试验，保留记录。

若单点小样效果好，下一步才是带两个摩擦点的完整打印核心测试，包括不均匀分担载荷、反向空程和紧固件松动。小样合格不能直接放行整机。外侧转动座、胸肩连接架、电子器件与线束也不能用小样结果代替。
