# O14 双轴核心试件

请直接打开 `PRINT_ORDER.zh-CN.html`，或访问 http://127.0.0.1:8769/tutorials/core-print/index.html 。HTML 已声明 UTF-8，包含支撑图、数量和装配测试步骤。

`O14_core_supplier_review.zip` 可发给服务商；里面是独立 HTML 与四件几何文件，不包含可直接上机的 G-code。C01/C02 必须启用支撑。几何 3MF 本身不保存支撑设置，请在真实机型/材料配置里重新切片。

本轮只改四件打印主体的摆放，没有改它们的机械尺寸。现有长臂小样继续保留；新试件用于双轴配合测试。M1.6 合拢螺钉和螺母商品尺寸未确认。零件说明中列出的切片参数是诊断起点，不是已通过实物试验的制造配置。

`generic_diagnostic_NOT_MACHINE_PROFILE.ini` 仅供复核本轮 PrusaSlicer 诊断，不应当作为 A1/P1S 的设备配置导入上机。
