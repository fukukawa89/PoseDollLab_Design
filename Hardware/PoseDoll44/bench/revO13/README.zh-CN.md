# O13 双轴核心试装说明

这是下一阶段的四件打印主体与标准件试装包，用来验证两个转轴同时工作时的配合。当前 O12 长臂小样已经收到“装配与初步手感通过”的用户反馈，仍用于补充负载和停留记录。

本包包含 C01、C02 两个叉架，以及 C14、C15 两个承力环半件。它不包含外侧扭转座、传感器、连接架或人偶全身。

- `print_beds/O13_core_fit_only.3mf`：四个主体的几何摆放，单位 mm；没有机器配置和 G-code。
- `print_beds/C01_on_bed.stl`、`C02_on_bed.stl`、`C14_on_bed.stl`、`C15_on_bed.stl`：逐件文件。

先沿用本次实际成功打印的耗材和工艺，并向服务商记录其名称与参数。当前反馈还没有这些数值，因此本轮没有声称某种材质已经通过实测。模型中的摆放需要服务商逐层查看孔、台阶及支撑，尚未执行实际切片。

## 装配顺序

1. 在环半件内放入四处 M3 螺母及其反力大垫圈，再放入环合拢螺母。螺母应坐进对应六角槽，反力垫圈坐进圆形台阶。
2. 合拢 C14 与 C15，用四颗 M1.6 螺钉连接。检查接缝贴合、内部标准件没有翘起。
3. 放入两片叉架。每侧从环向螺钉头方向的顺序为：M4 大垫圈 → 打印叉架耳 → M4 大垫圈 → 两片反向碟簧 → M4 普通垫圈 → 轴肩螺钉头。螺纹进入环内 M3 螺母。垫圈朝向和碟簧叠法沿用当前成功装好的小样。
4. 初始只给小预紧。逐侧小幅调整，确认左右两端能共同工作，再移动另一个转轴。调整目标是顺滑且能保持合适阻力，不是拧到尽头。

模型沿用了现货 6 mm 螺纹和 3 mm 内六角，内部反力台阶厚 2.8 mm。垫圈的图示公称孔径与批次实测公差仍未混为一谈；已有的一件成功装配支持复用该批零件。

## 本次真正要观察的事情

| 观察 | 怎么做 | 记录什么 |
|---|---|---|
| 双轴是否顺畅 | 先固定一个轴，转动另一个轴；再交换，最后同时小幅改变两轴角度 | 是否有突然变紧、卡住、刮碰或明显跳动 |
| 对侧预紧是否互相影响 | 每次只调一侧螺钉，然后转动对应轴与另一个轴 | 哪一颗螺钉改变了哪根轴的手感 |
| 环与叉架是否松动 | 从两个方向轻推同一位置，并观察环接缝、轴孔和叉架端部 | 可见位移、异响或反向空程，最好附视频 |
| 停留是否漂移 | 在一个容易观察的角度放开，按同一负载先看 1 分钟，再看 10 分钟 | 角度是否变化；是否需要重新调整 |

这些观察还没有发生。本轮小样通过，不能代替双轴核心的实测。手托人偶被允许，因此“不足以完全自保持”本身不再使方案失败；卡滞、裂纹、松脱以及无法获得有效角度读数仍需解决。

现有长臂小样的定量记录可先做：保留同一夹持位置，记录已知负载质量、转轴到负载重心的水平距离、停留时间和是否下滑。角度不为水平时不要直接把长臂总长当成重力力臂。当前 A8 弹力未知，本项目没有把旧目录 210 N 数值套在这批不锈钢碟簧上。
