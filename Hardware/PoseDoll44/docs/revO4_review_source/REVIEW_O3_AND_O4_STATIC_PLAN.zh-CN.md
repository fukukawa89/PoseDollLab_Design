# PoseDoll Rev O3 审查与 O4 静态摆姿采集实施方案

审查固定提交：`b2c54e380004c90317463fa5ef26c780171a0ce6`。被审查运行：`o3_20260924_r3`。

本文件是独立审查和下一轮任务建议，不是制造图纸、已布线电路、固件成品或实物验收。

## 0. 结论与范围

保留 O3 的机械主线、AS5048A 测角、六个逻辑区域和外置 G0。取消把持续 60 Hz、节点 8 ms、G0→END 14 ms 作为静态产品的强制门槛；不要回写旧运行或宣称旧实时测试变成通过。1.2 kg 继续只是偏好，不以超重强制重构。

推荐两条可并行、相互独立的 O4 工作线：

- S 线：先用已有模拟器/区域硬件架构完成“显式请求—新鲜扫描—稳定观察—完整快照—UE 原子 Capture”。这是当前主线，机械和电路未最终定型也可以测试。
- H 线：对比现有 14 芯远端板与“远端四路小 MCU＋独立半双工 RS-485”候选。只有真实总包络、带线动作、供电与通信试验显示收益才采用；不是先承诺更小板框。

S 线不依赖 H 线成功。H 线失败时保留现有 14 芯方案，不阻止静态采集交付。

资料由 GitHub 连接器读取；容器无法直接克隆远端仓库。本次没有完整重跑原 CadQuery 工程、KiCad、ESP-IDF、UE 或任何实物测试。独立执行了：

1. 按 O3 原尺寸局部重建前摩擦背板与止转槽的 CAD 求交；结果在 `results/backing_clearance.json`。
2. 静态事务、稳定观察及绝对角分支的离线参考实现，共 32 个测试；结果在 `results/static_tests.txt`。

这些测试证明的是列出的局部几何和软件语义，不替代原工程回归或硬件合格。代码中的候选尺寸、采样和时间指标均为建议，不是用户已冻结的规格。

### 2.1 反向空程的局部证据

源码中的前背片为 r=12.1 mm 圆环、两侧 `box(2.4,4.0,...)`，耳中心 x=±12.9 mm。杯槽为 `box(2.6,4.16,...)`。

前背片位于 z=-0.8..0 mm，这个截面的杯体是外半径 15、内半径 12.35 mm 的环；螺纹在后方，不涉及本次截面复核。按这些尺寸局部重建：±0.32° 无体积穿插；±0.33° 已有约 0.000192 mm³ 穿插；±0.35° 约 0.004864 mm³。

外耳最外角达到槽侧面的条件为 `14.1*sin(theta)+2*cos(theta)=2.08`，得单侧约 0.3252°、两侧约 0.6504°。这是名义止挡几何，非完整人偶输出回差实测；轴键、材料变形和其他接触未模拟。背板背面摩擦可能改变真实表现，但当前项目没有给它合格承力信用。

不要把 0.65° 当作编码器天然误差。传感器可能正确测得机械松动后的角度；影响的是摆姿落点、轻微扰动和反转手感。稳定等待能避免抓到移动中的中间角，不能提高机械抗扰能力。

候选改法：固定前背片采用明确的无松动定位；需要轴向滑动的后背片采用可调整/弹性消隙导轨或有供应商依据的配合。不能只任意收紧槽宽，因为会引入带扭矩轴向卡滞。分别测静止反转空程、滑动阻力、保持漂移和实际传感读数。

## 3. 静态模式：新产品契约

### 3.1 保留与取消

保留：41 测量轴、3 固定骨盆槽、轴序、原始角度/校准语义、真实机械偏置、可装配/维护、活动范围、静态精度/重复性、稳定持姿、错误隔离；480 mm 参考与 ≤500 mm 目标/≤600 mm 上限；外置设备方案与不设 1.2 kg 硬限。

取消强制：连续 60 Hz、原节点 8 ms、原 G0→END 14 ms、跨帧无停采握手优化及实时帧质量作为新产品唯一可靠性定义。旧版数据和门槛原位保留，标为 legacy，不重写结果。

不自动取消：传感器协议时序、电源与波形要求、无线功能/扩展意图、制造验收。此次方案不删除现有无线主控；仅比较在原无 MCU 的远端板增加局部 MCU。

### 3.2 建议初始指标（待实物验证，不是既定性能）

| 指标 | 初始建议 |
|---|---|
| 操作 | 摆好后点“采集当前姿势”；等就绪后预览或明确写 key。也可做单按钮“采集并写入”。 |
| 采样策略 | 平时低频预览可选 2–5 Hz；请求后约 10 Hz 完整扫描；各轴可顺序读取，无需同一微秒。 |
| 一次完整扫描跨度 | 目标/初始接受预算 100 ms。实际数值须由测得读数与链路预算验证；不能无限增长。 |
| 稳定观察 | 初始至少 500 ms 的保守共同窗口、不少于 6 次完整扫描；100 ms 调度与非零扫描跨度下通常需要 7 次。 |
| 稳定判断 | 每个轴全窗口展开后的峰峰值 ≤0.30°，拟合漂移率绝对值 ≤0.20°/s；属于待治具标定的检测参数，不是机械精度阈值的替代。 |
| 触发至完成 | 在线、健康、姿势已经静止时，p95 ≤1.0 s 为体验目标；用户事务硬超时初值 3 s。启动/入网另行统计。 |
| 最终数据年龄 | 提交时最后完整扫描最早采样边界至现在 ≤200 ms；最终取该整次扫描，不拿每轴的历史最好值拼接。 |
| 重试 | 每节点每事务最多两次额外尝试；受全事务 3 s 和单扫描预算约束。超过跨度则整个扫描作废重来。 |
| 验收样本 | 健康稳定台架至少 1000 次触发，≥999 次在 3 s 内成功；明确统计失败原因、p50/p95/p99、最坏值。该次数不等于总体失效率已获统计保证。 |
| 拒绝测试 | 预设故障/移动/重启/错 ID 测试集：不得误接收任何无效整身姿势。不是证明所有未知故障下零风险。 |

若噪声和检测阈值冲突，报告原始曲线，重新标定检测算法。不能通过抹平实际移动、无期限等待、用滤波掩盖系统误差或修改机械精度要求来通过。

机械保持 60 秒的原试验保留。采集只需短时间稳定，并不能证明放在桌上或受微扰仍能长期保持。

### 3.3 事务状态机与新鲜性

`IDLE → REQUESTED → SCANNING → WAIT_STABLE → FINAL_VERIFY → SNAPSHOT_READY → COMMITTED`

错误分支：`FAULT / CANCELLED / TIMED_OUT`。冻结的旧快照是历史对象，不是实时样本。

每个事务至少携带 device、G0 boot/session、capture_id、scan_id、源节点 boot/generation、profile/calibration hash、完整轴集合、状态位、CRC、G0 单调时钟的采样包络。重复请求是幂等查询/同一请求重试，不能重复写 key。

采集开始清除/隔离旧接收缓存。每节点须收到当前请求后产生新扫描，不允许“回传缓存角度并给它新时间”。丢节点、坏磁场、传感器错误、旧包、重复片段或中途重启，不能用旧值补齐 41 轴。

稳定只在连续的新鲜完整扫描上评估。慢漂移不能只看相邻帧差；角度跨 0/360° 要正确展开。对准采样间隔的周期运动可能混叠，因此稳定观察是有限观测，不是“期间绝对没动”的数学证明。对摆姿场景增加轻微采样间隔抖动、移动提醒及针对周期运动的测试。

初次实现不关闭传感器电源；以后再比较待机省电。否则上电磁场诊断、热漂移、重新稳定等待可能抵消复杂度收益。

### 3.4 时间戳和协议迁移

旧 PD41 v1 的节点字段使用 uint16 微秒数；100000 被截断后为 34464。这是算术溢出，不能靠改变阈值解决。

推荐新静态协议 `PDS1`（建议名称，单独版本和消息类型），新持续时间用 uint32 微秒、会话时刻用 uint64 单调微秒。不要把微秒悄悄变成毫秒。消息必须带长度上限、CRC、消息类型和精确片段/轴身份；CAN 分片也使用 capture_id/scan_id，并校验完整分片集合。

保留 PD41 v1 的 legacy 编解码器、测试与日志。可作为过渡输入，但不能把 300 ms 的快照硬编码成 v1 的 10 ms 新鲜批次，也不能伪造节点计时。

外部 G0 可顺序发起六区扫描，G0 的请求发送与响应接收给出保守共同时间包络。区域本地 duration 是局部时间差；未做同步时不得把多个独立时钟的绝对值直接相减。

原始 CAN/节点日志仍用于验证驱动时序与出错恢复，但 8/14 ms 不再是静态合格数字。新的 capture_metrics 以请求总数、真实墙钟等待、扫描跨度、最终年龄、重试和恢复为核心，不能把分母硬编码成 60×秒。

### 3.5 UE 必须同步改

`DollSimulation/README_PoseDoll.md` 明确 Live 250 ms Stale、1 s Frozen；`ARCHITECTURE_PoseDoll.md` 表明连续角展开、接收只留最新完整样本，以及 Capture 是单一 Undo 事务。

O4 要做独立 Snapshot 工作方式：

- Preview 心跳不等于测量；最后有效快照显示“采集于…”，不刷时间伪装持续新数据。
- 事务命令和快照不能被 Live 的“只保留最新帧”槽丢掉；独立有界队列、回执及幂等 capture_id。
- 网络线程不操作 UObject；验证后的全套原始角度交给游戏线程原子更新，沿用 UE 的校准、FK、Rig 映射和 Capture 回滚。
- 低频甚至间歇式采集不能根据前一姿势的最短角差猜测多圈分支。对单圈传感器用标定＋真实硬限位求唯一绝对机械角；不唯一时拒绝并请求归位/已知基准。参考测试包含从 +170° 到 -170° 的静态切换。
- 请求时捕获目标 actor、sequence、binding、播放头、mask、Clutch 基准和 profile 版本；等待时它们改变，取消或要求重确认，不能把旧请求写到新的帧或角色。
- 采集等待的真实秒数与动画时间轴无关；写入用户指定播放头，Capture+前进仍按既定动画帧步长。
- 超时/断线保留已经写入的动画和历史快照，不自动覆盖手工编辑。

## 4. 硬件候选：比较后推荐

| 方案 | 真实收益 | 代价/故障范围 | 推荐 |
|---|---|---|---|
| A：原硬件＋静态轮询 | 最少变更；不再需要严格实时调度 | 板、14 芯 J50、全部原缓冲/接头基本不变 | 立即实现，作为工作基线与对照 |
| B：片选解码/串行扩展 | 可能减少部分控制线/主控 GPIO | 简单 2→4 解码仍需两地址＋使能，只比四片选少一线；共享 SPI 仍跨肩；串行扩展需防错误选通/MISO 争用 | 只做有确切净收益的候选，不默认能变成四芯 |
| C：远端四路就地采集＋点对点差分串行 | J50 这一条可由 14 芯改为四芯，隔离跨肩共享 SPI 与 MCU 原始片选 | 每臂新增一颗小 MCU、两端各一颗收发器、调试/供电/协议；通信故障可局限四路；电源故障范围取决于支路保护，任何缺轴使整身 Capture 失败 | 首选结构优化实验，不先保证 PCB 一定缩小 |

降采样频率、降低串行时钟、减少线数是三件不同的事。C 在实时系统中也可能成立；静态需求使其轮询、重试与局部额外时延更容易满足体验目标，而不是发明一种实时场景不存在的硬件。

### 4.1 C 方案的具体连接

```text
PC / UE ←标准 USB→ 外置 G0
                       │ CAN + 电源（现有主干保留）
             N1、N2、N3、N4、N5、N6
                         │      │
                  N3 近端5路  N4 近端5路
                         │      │
                    四芯点对点 RS-485
                         │      │
                  D3 四路采集  D4 四路采集
```

每条四芯链路为 `3V3、GND、A、B` 的初始候选；A/B 绞合，地是必要的参考和电源回流，不是可删除的第三根数据线。验证负载、最小电源、电缆/接触压降；3.3 V 余量不足时比较 5 V＋局部 3.3 V 稳压，但仍是四芯、相应计入板件。

这只是 J50 这一条链路变为四芯，不是所有穿过肩部的传感器线合计仅四根。近端五路中安装在不同活动件上的传感器线仍按所属刚体布线，必须把它们计入完整线束和恢复力。

兼容映射：六个逻辑区域仍为 3/6/9/9/7/7；N3/N4 各汇总自己的 5＋4 路。D3/D4 不增加 CAN 地址、不占第七/第八测量槽。物理 CAN 节点仍为 G0＋六区共七个；处理器数量增加到九颗，须如实记录。八块主要采集 PCB 可以仍是八块，其中两块远端板从缓冲板变为 MCU 采集板。左右从板的 boot/generation 身份要传到事务协调器。小 MCU 没有独立随机源时，不得使用每次上电相同的伪随机种子冒充新 boot：复位后清除 joined 状态，由近端用新的会话 nonce 建立链路代际，重新加入使当前候选事务失效；旧会话命令不可在新启动后直接执行。

### 4.2 实际器件起点（不是采购/布线放行）

- 小 MCU：`STM32C011F6U6` 作为候选，UFQFPN20 3×3 mm、32 KB Flash / 6 KB RAM，具 SPI、USART 与 SWD。ST 官方 DS13866 Rev 5 给出封装和订货代码。需冻结 SPI 模式 1、250 kHz 基线下四片选、USART、DE、SWD、复位的真实复用引脚与内存预算。不得只画一个 MCU 方块。
- 两端差分收发器：`THVD1400DRLR` 候选，最高 500 kbps；DRL 包体约 2.1×1.2 mm、含引脚典型总宽约 1.6 mm、最大高度 0.6 mm。起步采用 115200 baud 半双工、一个主机发起轮询；DE 上电/复位默认禁发。器件的失效安全/ESD能力不替代板级供电、回灌和热插拔合格。
- 四针接头：`SM04B-SRSS-TB` 或 `BM04B-SRSS-TB`＋`SHR-04V-S`，厂家头部宽 6 mm、无凸耳线端壳宽 5 mm；14针对应16/15 mm。完整 courtyard、固定脚、壳体、压接端子、线尾和维护空间全部保留。线端由供应方压接，不让用户手工焊微型线束。
- 传感器、磁铁和四个传感器端口先保留。远端本地 SPI 缓冲是否能删，必须由短线波形、共线争用、逐端口故障隔离与失电测试决定，不能因为有 MCU 就全删。
- 新增 MCU 需要供应商烧录/测试治具与 SWD 测点。四芯运行链路不承载 SWD，不把独立调试线长期穿过肩。

主控 N3/N4 仍保留现有 ESP32-S3，故不在此步骤删除既有无线硬件。以后若将主控也换成无无线芯片，需单列无线需求、实际未使用功能与迁移决定；用户仅取消实时动捕，没有授权删除其他功能。

### 4.3 包络、线束与时延预算

首版远端原生板以原 26×30 mm 作为对照，20×30 mm 为研究候选，不是承诺。即使面积不缩小，只要四芯带线扫掠、插拔和手感改善，也可能值得采用；反之若总装更厚、更难维护，就保留 A。

按相同外径 0.8 mm、填充系数 0.65 的几何估算，14 芯等效束径约 3.71 mm，4 芯约 1.98 mm。实际护套/绞距/线规和弯曲刚度未计，不能宣布直径、阻力或疲劳寿命按此比例改善。不得把旧 4 mm 弯曲半径自动视为新线合格值。

115200 baud、8N1 下，假设一次请求＋响应合计不超过128字节，纯串行时间为 11.11 ms，另外计四路读取、换向、CRC、调度与重试。这个数量级允许将几十毫秒放进静态扫描预算，但不能冒充实测上界。新消息实际长度、CRC/header、原始角度、错误位、capture_id、scan_id、boot_id 必须先冻结，再计算。

保持主干 CAN 500 kbit/s 和传感 SPI 250 kHz 为初始基线即可。没有必要为了“低频”同时把所有总线降速或更换主干。全链路轮询、最坏扫描和失败时超时要实际测量。

成本不能先许诺降低。每臂多 MCU 和两端收发器，也可能减少主控侧长线驱动、片选电阻、宽接头与压接芯数。报价比较必须包括 PCBA、两种工具链、烧录测试、线束、接头和返修。

## 5. 机械结构怎样进一步优化

静态模式不自动降低重力矩，也不缩小磁铁/轴承/螺丝。收益主要来自电子和线缆：小接头、少跨关节芯线、就近采样，可减少走线槽、服务弯、线束恢复力及为大板让位的支架。只有重新计算且实测线束力矩后，才能相应下调预紧。

保留连续可手掰的摩擦摆姿为主操作方式。不因“静态”就改成每个关节都要松螺丝—摆—锁，这改变了用户体验。如果某个高载荷轴的实测手感仍不可接受，可以另做单轴释放/夹紧样件对照，但不能擅自推广到全身。

也不要求继续为 1.2 kg 开发新关节族或极限镂空。优先用较厚实、可加工、可维护的结构关闭 P0。只是当 L6 的包络/力矩/阻力不适合某轴时，才有必要修改规格。

当前单关节约45.29 g是参考，不是每个轴都要采用它。实际肩部多轴、胸腔板和单臂共同布局仍必须做；本轮不要一边无限完善独立关节，一边永远不检查总成。

## 7. 下一轮必须执行的测试

### 7.1 软件与协议

- 请求前缓存、错 capture_id、错 scan_id、迟到重试、重复片段、缺片、CRC、断线、G0/N3/D3重启、profile/calibration变化。
- 正常零角度与固定/缺失/故障区分；全身输出44槽且41轴均为正常当前数据。
- 100 ms/300 ms边界无 uint16 截断；uint32/uint64回绕/非法值处理；测量时间、接收时间、等待时间分别记录。
- 角度跨0/360、两次姿势超过180°变化、硬限位多解拒绝、慢漂移、短暂移动后回位、周期运动、长暂停。
- 单击一次只提交一次；超时不留半套控制器；切播放头/切目标/Undo期间到达快照不能写错对象。
- UI Snapshot保持历史结果不伪造新鲜流；断线不丢已写动画。

本包 `static_capture_reference.py` 及32项测试用于语义讨论与移植起点；它不包含电气报文分片、安全启动、完整源配置解码、硬件驱动或UE接口，不能直接称为O4生产实现。

### 7.2 四路台架

同一组四个实际传感器，原14芯与新4芯采用相同动作和电源条件对比。记录角度误差/重复性、采集时间、CRC/超时、每路供电最低值、温升、线束恢复力及故障影响范围。必须覆盖掉电/断地/断A或B/传感器断线/共享返回争用、反复复位和连接器插拔。电源故障在受控限流下由有条件的供应方进行。

RS-485 DE、接收使能、端接与偏置按点对点实际线长/边沿确定；不能简单把 CAN 的端接和脚序照搬。近端和远端共参考地不等于已完成所有共模/电源验证。远端电源应有可核算的支路限流/隔离；未经短路和复位验证，不能声称远端故障只影响四轴。

### 7.3 机械样件与单臂

保留原目标：全范围校准后误差≤1°，重复性≤0.3°；真实线束下60s漂移≤0.5°；邻轴扰动与机械串动分开记录；初筛1000次往返。新的背板反转空程不得与传感器精度混算。

输出接头、刀具/扳手、配合线头、磨损状态与防脱结构先完成，才由供应方试制对应受载样件。摩擦材料小片可先做，不必等全身CAD。局部试样许可与整机制造放行分开。

## 8. 需要用户决定的事项

现阶段不需要用户批准更大身高、更重“上限”或减少轴数；旧1.2kg硬限已经取消。建议参数是本轮工程起点，先让软件和试样验证。

只有需要改变直接手掰操作（普遍改手动锁紧）、删除无线需求/明确功能、突破尺寸/动作约束，或新增硬件方案成本显著改变时，才请求用户决定。常规的报文、退避、4针/14针对照和局部保持结构由Codex按本任务进行，不应把每一步普通工程判断都退给用户。
