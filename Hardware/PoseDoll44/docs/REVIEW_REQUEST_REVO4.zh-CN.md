## 保持的约束

480 mm 桌面方案、91 cm 备用、41 测量轴和 3 固定骨盆槽、外置 G0、6 逻辑区域、7 CAN 节点与无线功能继续保留。整机 1.2 kg 不是硬门槛，但重量、重心、保持力和操作力仍需核算。用途是摆好姿势后采集，不能以旧 60 Hz / 8 ms / 14 ms 动态指标否定静态模式；仍需保证数据完整、稳定、事务一致与有限超时。

## 请重点判断

1. PDS1 稳定窗口、最终完整扫描、boot/配置/校准绑定、CRC、时长范围和有界缓存是否有遗漏；UE Capture/Undo/Redo、上下文取消、快照去重和骨骼回读是否可靠。审查模拟证据能支持的范围，以及下一步实体网关适配的最小闭环。
2. 四芯 C 是否值得继续。20×30 顶出线远端板面积减少 23.1%，但近端加远端的包围盒总量仅减少约 3.1%；R4、R12 与服务空间反而增加约 5.1%、8.2%、12.3%。请以完整胸肩/单臂、全部其他线束、RF 和维护路径判断，不以 PCB 面积代替整臂收益。
3. A 与 C 均未布线，完整 PCBA 配合仍未合格。确定应先完成 A 的静态固件，还是投入 C 的布局/布线、供电和 STM32 外设驱动；列出明确的继续/停止条件。
4. 3.3 V 供电敏感性有 4/36 组低于 3.0 V，250 mA 档可能触发限流。判断短路径粗线是否足够，何时应独立比较 5 V + 本地稳压；不要把假设压降当成实测。
5. 外耳止挡约 0.65043° 名义空程、槽角薄壁及受载轴向滑移仍未关闭。给出力路、输出夹持、摩擦结合、试片和反向扭矩的下一步顺序，避免只缩公差或增加弹簧力。

## 证据边界

61 个 Python 测试、4 组 UE 自动化、真实编辑器写键与新进程重开、1000 次模拟源串行请求及最终解码器重放均通过。1000 次是本机模拟 TCP 请求，不是实体人偶试验，也不是 1000 次 UE 写键。主机 C 链路测试不是 STM32 驱动验收。
