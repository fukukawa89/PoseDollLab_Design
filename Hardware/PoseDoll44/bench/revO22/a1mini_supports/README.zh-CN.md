# O22 · A1 mini 单材料 PLA 支撑工程

适用：**Bambu Lab A1 mini、0.4 mm 喷嘴、普通 PLA、单材料**。采用本机 Bambu Studio 02.08.02.61 切片。床面沿用上一版的纹理 PEI；如果实际使用光面板，请在 Bambu Studio 中改成实际床面并重新切片。

本版保持 O22 零件尺寸、主盘 A01–A10 的编号、摆放及 186 件数量（185 件整机零件 + 1 件量规）。原版几何包和拼装教程继续有效。S00 是新增的 7 件试印备件，T01 是原有的可选传感器小样；两盘都不计入整机用量。

## 应当打开哪个文件

打开 `projects/` 下的 **`*_PLA_supports.3mf`**，在 Bambu Studio 中选择“打开为项目”，保留项目配置。文件内含 A1 mini 机器、Generic PLA、工艺、逐零件设置和支撑涂色。不要使用旧 `a1mini/plates/` 的几何文件作为本版打印工程。

文件同时保存了本机生成的切片。修改耗材品牌对应的温度、床面或其他设置后，应重新切片。不需要连接打印机即可查看；本版没有发送任何打印任务。

“准备”页面可能显示半透明的禁支撑区域，它们不参与打印，请保留。实际打印内容以“预览”中的零件与支撑路径为准。

不要再次自动摆盘、自动朝向或缩放。本次排布已按支撑和裙边核查；更改位置可能改变支撑树的路线。按层打印。

## 先打印 S00

建议先用 `S00_support_trial_PLA_supports.3mf`，暂不整套开打。试盘中的七件均为原尺寸的实际零件，可以作为备件：

| 零件 | 检查重点 |
|---|---|
| P130 踝部 C14 | 很窄的底部是否稳定；外侧支撑能否拆除；M1.6 小孔是否畅通 |
| P033 头部 C01 叉臂 | 多层环形悬空的表面、支撑拆除通路与肩轴孔 |
| X005 传感器托夹 | 托住悬空细轨；PCB 滑入顺畅；0.8 mm 弹片不被扯断 |
| N003 侧装磁铁座 | 不启用支撑；磁铁侧入口与座孔的桥接质量 |
| X045 半轴壳 | 开口中的可拆支撑、螺丝孔和板夹槽 |
| H004 肘部骨架 | M3 螺母侧槽、0.95 mm 垫片入口及外部悬空 |
| P036 C15 环 | 关闭支撑后的小孔顶面桥接与孔口配合 |

待完全冷却后取件。检查支撑是否能分段取下，再用计划使用的螺丝、垫片、磁铁和未通电 PCB 试装。先不要粘磁铁。通过后再打印 A01–A10；试盘未通过时不要直接把同一问题复制到整机。

## 本版的支撑处理

- **骨架、叉臂、轴壳和需要托底的细轨**：使用限定表面区域的贴合支撑。非必要面禁用支撑，孔槽上方也设排除区，使支撑不会从更高处穿过功能孔槽。
- **宽阔的内部开口**：例如胸部背盒上沿和上下叉耳之间，保留必要支撑。允许支撑落在本体上，底部也留分离间隙；从开口分段取出。
- **磁铁小座、端盖和适合短跨桥接的小件**：关闭支撑，避免支撑残留在安装腔内。实际桥接效果由 S00 和首件确认。
- **精密孔槽**：对已识别的功能面禁用支撑，并设置从孔槽延伸至上方的排除柱体；按实际切片路径检查已建模的孔槽保护区域。保护区的范围与遗漏项记录在验证文件中；这不是对所有空腔和取出路线的数学证明。
- **底部较窄的零件**：配置外裙边稳定打印；裙边与本体留间隙。切片器可能在支撑底座覆盖处省去独立裙边，应以首层实际路径为准。裙边和支撑是两种不同的辅助结构。

| 项目 | 设置 |
|---|---:|
| 层高 / 首层 | 0.20 / 0.20 mm |
| 支撑 | normal(auto) / snug（仅指定区域允许） |
| 上接触 Z 间隙 | 0.28 mm |
| 下接触 Z 间隙 | 0.28 mm |
| 独立支撑层高 | 开启 |
| 支撑与模型 XY 间隙 | 0.45 mm |
| 顶部 / 底部接触层 | 2 / 2 层 |
| 接触层线间距 | 0.50 mm |
| 主体线间距 | 3 mm |
| 首层支撑扩张 | 0 mm（防止底座扩进孔槽） |
| 首层支撑与零件间隙 | 0.45 mm |
| 外裙边 | 按零件为 0、1.5 或 3 mm |
| 裙边与本体间隙 | 0.15 mm |
| 外墙数 / 稀疏填充 | 3 / 20% |

这些间隙是针对单材料 PLA 的初始工艺选择，会牺牲一些支撑面底部的平整度来降低粘连。实际可拆性取决于 PLA 配方、干燥情况、流量与温度；数字切片不能替代一次实物试印。不要把本版视为已经完成过物理拆除试验。

## 拆除顺序

1. 等打印盘和零件冷却后再取下。先剥离外裙边，露出支撑底部。
2. 用手或钳子握住支撑主体，轻轻向远离零件的方向分段拆开。支撑较宽时，先剪断支撑之间的连接，再拆接触层；不要一次扯整片支撑。
3. 传感器托夹要握住圆形安装耳或较粗连接臂，沿细轨下方横向剥离支撑。不要拉 PCB 导轨、弹片或把它们当撬杆。
4. 胸部背盒从宽开口拆出内部支撑，先拆能抓到的支撑主体，再拆顶壁接触层。叉臂从两臂之间的开口逐段取出。
5. 检查孔槽和磁铁安装面。不要为了清支撑而扩大已验证过的配合尺寸；如果需要明显钻削才能装配，先检查工艺或支撑是否进入了本应保持空出的区域。

若支撑仍太粘，可先只在 S00 对应零件上把顶部间隙试到 0.32 mm；若悬空底面明显下垂，可回到 0.24 mm。每次只改一项并重新切片。细轨支撑高度很低，不能盲目继续加大间隙，否则支撑可能无法形成。

## 验证范围与来源

每盘保留原生导入/切片结果、几何与逐面标注检查、全部打印路径的床面边界、孔槽保护区域的路径检查。机器启动擦嘴和收尾运动不属于零件打印路径边界验证。正式工程另外不附加外部配置重读切片，以确认设置保存在项目内。
