  1. 点“播放本步”，看橙色零件怎样对准蓝色位置。
  2. 默认每个动作播完就停。装好后点“下一步”；看不清可以慢放、拖动、重播或打开“看内部”。
  3. 左侧可搜索型号、盘位、关节或电路端口。右侧“看它在哪一盘”显示当前 D01–D15 的实际盘图。
  4. 电路动画包含磁铁、传感板方向、46 路接线与分段上电检查。以工厂预焊并检测好的电路板为起点。
  5. 不含拆支撑过程。194 件打印件中，186 件装机，1 件工厂焊接量规、7 件可选小样不重复装机。

模型使用 O22F7 永久本体。动画表示装配动作与顺序；弹舌的弹性、胶固化、线束余量和通电结果需要实物检查。电路上的数字与线色用于识别，动画不会替你认定实物已通过。
