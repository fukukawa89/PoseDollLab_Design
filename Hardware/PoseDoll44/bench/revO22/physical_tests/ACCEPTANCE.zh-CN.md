# O22 首件与真实采集验收

本文件的步骤已经准备好，**尚未进行下面的实物测试**。O11原有尺寸配合和可调摩擦已由用户通过；这里只增加传感器和数据链验证，不重复测试摩擦原理。不要将数字测试的合成数据填入实物记录。

## 1. 在已有O11小样上测试新传感板

`physical_tests/sensor_coupon/`含两个新增可拆支架的STL与3MF。

- `sensor_bridge`通过原底座(-20,-9)的M4安装通孔固定；原夹具螺栓有效长度增加约3.0mm。磁铁面对面位于转轴正上方。
- `magnet_bridge`安装在原长杆x=100mm的M3通孔，用M3×25、M3螺母和两片普通M3垫圈固定。它随长杆转动；磁铁D6×2.5径向充磁，压入/固定在顶端座中。磁铁不可碰到编码器封装。
- 保留原底座、长杆、肩轴和全部摩擦垫片；两个支架不参与调整关节摩擦。短行程试验限0–60°，数字采样每5°无新增刚体相交；这不是340°运动能力验证。
- 固定支架内的传感PCB元件面向磁铁；装48板中的一块首件即可。不要复制一套完整人偶给小样。确认板面平整、磁铁不偏心，外壳间隙按1.00–1.75mm目标实测。
- 先用限流电源带1块传感板，检查VDD、GND及无短路；再看SSI已知角度、CRC、磁状态、回读方向。不能把“有数字”当作角度正确。
- 示例拟合点0/15/30/45/60°，独立验证点5/20/40/55°各正反向到达；每点≥20个样本。此小样验证新接口，不替代46轴安装后的逐轴标定。

## 2. 16路并联负载与最长线束

中央板先接1路，再接同一bank的16路。保留600mm条件作O21对照，再用本版最坏750mm线束。至少选近端、远端各一路同时测VDD和SSI，负载保持到温度稳定。

| 测项 | 判据 / 记录 |
|---|---|
| 输入 | 适配器额定5V/2A；加载出口≥4.9V；输入线压降≤0.08V；U7 VIN≥4.05V |
| 远端电源 | 工作时最低≥3.10V；不得越出传感器3.0–5.5V绝对使用范围；记录瞬态谷值和纹波，不只记万用表平均值 |
| 逻辑最高电压 | 传感供电/相关LVC电路≤3.6V |
| F5压降 | 测热态电流与保险丝压降，折算≤0.15Ω；0.071Ω是目录标称冷态值，不是验收上限 |
| 温升 | 记录室温、L1/U7/F4/F5最高温与稳态时间；所有器件在额定范围，无反复PTC动作或棕断复位 |
| SSI | 保存示波器或逻辑分析仪原始文件。检查远端建立保持、边沿、反射/过冲、CSN高期间DO上拉诊断；不能只看解码文字 |
| 通信 | 连续≥10000轮完整扫描，不得出现被接受的CRC错误、丢通道、混合boot或混合capture；被拒绝次数也必须记录 |
| 拔线/卡低/陈旧数据 | 故障必须导致明确拒绝，不能输出0°假姿势；恢复后重新发起采集，不拼接旧窗口 |

压降模型按铜层60°C、反馈电阻相对25°C最多±40°C计。若实测铜层超过60°C或反馈电阻超过65°C，须按实测温度重新计算，不能仅凭低于器件绝对额定温度放行。

这是设计验收目标，尚无实测结果；达不到时修改首件工艺、波形或供电，再重复失败项。

## 3. 完整左臂及定长

先装锁骨2路、肩4路、肘1路、前臂1路、腕2路共10路。按`harness/routing_plan.json`固定到各自骨段；不跨转动缝扎死。插拔余量、板边柔性固线和关节U形环必须保留，最小弯曲半径7mm。打印一根直径14mm参考圆柱或用对应圆棒检查弯曲，不能把导线路径的直角折在线材上。

在实际无刚体碰撞的可用范围内，缓慢操作每个自由度，再组合抬臂、屈肘和转腕，记录视频或逐步照片/文字位置；本设备工作不依赖摄像头，验收记录方式由操作者选择。不得拉动焊点、磨到螺钉边、进入垫圈/摩擦面、扭成紧绳。做至少200次往返筛选并复测导通及角度零点；200次筛选不代表寿命保证。先由加工方按预切长度做首件，确认后回填长度，余量不能在用户端要求重新焊接。

注意：`mechanical/adjacent_regression.json`含旧有极限姿势相邻接触，不能强行摆到这些位置。原始编码范围不等于机械无干涉范围。若实际使用需要这些姿势，需调整相关外形/限位并重新验证后再放行；本轮不以改编码零位隐藏碰撞。

## 4. 每轴安装后标定

复制`axis_samples_EMPTY.json`填写真实USB设备号、轴号、独立参考夹具及其不确定度。关节角使用固定机械基准；A站姿只是摆姿，不是把46轴全部设为0°。对实际能达到的有限行程布点，拟合间隔≤15°，两端有独立校验；到不了的角度不能补造数据。参考夹具不确定度≤0.1°。若没有符合要求的仪器，可借用或委托；费用必须计入实际成本。

每次停稳≥20次读数、峰峰值≤0.3°。每轴用`source/calibrate_axis.py`拟合并检查独立验证最大误差≤1°、双向差≤0.3°。越出已测校准区间会被拒绝，不能外推。保存所有原始记录，不只保存一张误差结论表。

把11项实测记录填入`test_manifest_INCOMPLETE.json`；每个PASS项必须有真实文件和SHA-256，source_kind为MEASURED_HARDWARE。`source/assemble_calibration.py`检查46轴完整性、设备号与证据文件散列；未测试项目保持False，不能获得正式导出资格。软件只能检查文件一致性，无法替代操作者对真实测量的负责。

## 5. 真实46路→UE→保存重开

全部通道安装、标定并通过故障测试后，用真实COM端口采集，保存原始P21R包。主机正常导出时不加synthetic测试选项。分别选Manny和Quinn对应profile，将不少于A站姿、左肘、非对称、前臂扭转四个实测姿势写入明确选中的Control Rig序列。

检查逐骨方向，尤其左右符号、锁骨、肩轴组合、前臂扭转和脚踝。保存关卡/序列，关闭采集程序与UE，再开启UE读取已保存资产，不重新播放源JSON。关键帧应保持、可编辑和撤销；保留资产路径、版本、截图与数值误差记录。目标角色骨长与外壳接触不是本设备的实测输出，不添加接触IK修正。

## 记录与放行

R11/R12需要实物/报价证据才能关闭；当前空表不是错误，而是如实表示未测。首件返修前后分别记录板号、打印批次、固件哈希、标定哈希、测量温度和原始数据。正式报价合计≤1500元与技术验收通过是两个独立条件，必须分别成立。
