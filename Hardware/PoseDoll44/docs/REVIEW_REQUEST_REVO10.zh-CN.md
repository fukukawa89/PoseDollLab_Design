# O10 评审入口

先读[本轮设计报告](O10_JOINT_AND_TEST.zh-CN.md)，并打开[交互说明](../tutorials/design-lab/index.html)。工作区尚未提交本轮commit；评审以`o10_20260926_r1/evidence_manifest.json`锁定文件。

请重点审查：

1. 端面制动、独立磁铁支撑及金属轴的力路；210 N为目录点，未测摩擦/蠕变，外侧转轴制动与M3轴防松仍开放。
2. 连续叉架间隙与完整关节端点检查的范围区别；零面积面处理、初始实体分离和数值误差。
3. 参考螺纹的旋出、套筒/肩轴支持、铝环结合与生产牙形/公差缺口。
4. 双轴锁骨试排的双侧前收碰撞，以及未建承力连接架、胸颈和带线总装。不得删除失败目标来获得通过。
5. LPMS-05D的版本、安装、引线与真实通信性能；目录尺寸和宣传不作为电气验收。
6. 独立摩擦小样是否足以回答当前尺寸决策所需问题，以及下一轮完整关节试验还需哪些测量。小样结果不能当整机放行。

用户没有硬件，所有记录留空；0.3°漂移、20 N操作力仍只是旧有暂定筛选线。重量不以1.2 kg作硬门槛。
