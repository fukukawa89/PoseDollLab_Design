POSEDOLL / O24E / R5 / 2026-10-30

通电、标定与角度验收

本包没有真实传感器采集数据。空白模板不能输出可信姿态；实测及独立验证全部通过后，calibrate.py才生成可用标定。

固件源码/构建 · 已编译固件哈希 · 采集器 · 标定器 · 姿态导出 · 测量模板

固件仅面向R5专用接线/O22载板/XIAO ESP32S3；烧录方法见firmware_release/FLASH_README.txt，必须指定实际COM口。本次没有连接或烧录硬件。主机依赖：python -m pip install numpy pyserial。

标定前

  1. 原摩擦、防脱锁固完成，磁铁及六角填隙胶固化。六路MT实际封装表面间隙在0.5～2.0 mm内、偏心≤0.3 mm；先消除擦碰和晃动。
  2. 所有黄铜/原R4钢件和线束装齐再标定。MT场强状态正常，WD用±100 mT档，任何分量接近95 mT限制、CRC或状态异常均拒绝输出。
  3. 轻拉磁铁盖/板托不能退出或转位；每轴往返20次后回零漂移≤1°。超差先修复夹持/六角回差，不反复标零掩盖。
  4. 附件和走线装齐后复核代表姿态保持力。需调AX4时先拆测角附件，最终机械调整后完整重标。

实际采集

用可靠机械角度尺在每个关节两侧建立参考。上臂/前臂旋转按自身轴和零位测量，不用手掌倾角冒充。记录参考工具、夹持和读数；A字HS=45°，其余可调角0°，RF固定−90°不重复加入。

复制模板为measurements.json，按174条记录分别采集，每条独立文件、≥25个有效帧。普通标定固定其余轴；cross_joint/coupled改变其他轴，同时独立测量被检轴参考角。

python arm_reader.py --port COM实际编号 --seconds 2 --output captures/RP_calibration_01.json
python calibrate.py --manifest measurements.json --output measured_calibration.json
python arm_reader.py --port COM实际编号 --seconds 10 --calibration measured_calibration.json --output accepted_capture.json
python pose_bridge.py --capture accepted_capture.json --calibration measured_calibration.json --output arm_pose.json

从electronics目录执行，先创建captures文件夹；替换实际COM编号，不自动探测端口。R5AR v1协议280字节，名义50 Hz扫描，单次≤55秒，结束发送STOP。

验收门槛

检查要求
分轴标定每轴≥11站，覆盖全程；WD间隔≤5°，用实测XYZ矢量曲线。
正向/反向独立验证各≥5站，最大误差≤2°、RMS≤1°，每站静态峰峰≤1°。
相邻关节干扰六路MT各≥3组不同关节组合；被检轴参考角由机械尺读出。
腕交叉WF=−65/0/70° × WD=−20/0/30°共9站。只转一轴时另一路稳定。
WD曲线静态分量标准差≤0.1 mT，局部灵敏度≥0.15 mT/°；残差合格且无多解。
数据SSI CRC6/状态、TMAG CRC4/转换计数/错误位/配置、USB CRC32/会话/序号全检查；故障停止，不沿用旧角。

这些是工程验收目标，不是已经测得的精度。打印误差、钢件磁化、磁铁强度、长线波形和蠕变需要实际确认。独立验证失败时程序拒绝合格标定，保留原始文件排查。
