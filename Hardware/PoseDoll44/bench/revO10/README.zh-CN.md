# O10 独立摩擦试验：先知道能否稳住，再定关节尺寸

**这不是整臂打样，也不是孔径测试。** 要测的是：真实 PA12、钢片和碟簧组合，在可调范围内能提供多大的保持力、是否难以转动、停留后是否滑移。没有硬件，因此记录表的测量栏全部留空。

先打开[动画页面](../../tutorials/design-lab/index.html)，选择“04 看测试”。页面中的配重和细线只演示加载方向，不预测保持效果。

## 为什么现在需要这个数据

当前悬空臂模型要求弯折轴约 **0.392 N·m** 的保持力。按两侧各承担一半的初步分配，单侧试验的筛选下限约 **0.196 N·m**；真正的双侧载荷分配仍须在完整关节上检查。100 mm 水平力臂挂约 200 g，即产生约 0.196 N·m，此外还必须计入长臂自身重量。

两片 A8 碟簧反向串联，并不会把 210 N 变成 420 N。厂家目录点为单片高0.45 mm、力210 N；目录也列出了薄碟簧的力偏差。例如按二级偏差，该点可能对应189～273 N，具体等级须与供应商确认。这不是实测值。[锐尔立目录](https://www.raleigh-spring.cn/discspring/list_84_2/)

按现有双侧端面模型和210 N估计，有效摩擦系数需约0.21；若取189 N，则约需0.24。自由钢片、钢片与铝座接触、实际表面、压力分布和塑料蠕变都会影响它。继续假设一个系数来定碟簧数量、轴长和关节直径，会把这个未知量带进胸肩设计。

**测试结果用于决定保持现有尺寸、增加弹簧组，还是扩大摩擦面。** 当前胸肩试排还有双侧前收20°的碰撞；这个试验不会使该结构自动合格，也不代替后续的避让、连接架及完整带线总装工作。

## 如何装和测

1. 将底座固定，**中心轴水平放置**。绿色长臂在竖直平面中转动。顺序为：铝底座 → 内钢片 → PA12长臂 → 外钢片 → 两片反向碟簧 → 前承压垫圈 → 螺钉头；背面是后垫圈和螺母。
2. 清洁并记录实际表面状态。使用干燥接触作为本次候选，不能一件上油、一件不处理而混成同一组数据。拍照记录两片碟簧方向。
3. 先将两片碟簧的总压缩高度设在1.10 mm，记录实际读数；随后研究1.00、0.90 mm。不要把拧螺钉的力矩或这个高度写入“实测轴向力”栏，没有测力设备就把该栏留空。不以压平弹簧来增加保持力。
4. 称长臂自重，测它的重心到轴心的水平距离。将长臂置于水平，在距轴心约100 mm的孔上挂小配重，逐步增加并称量容器总质量。挂线应竖直。实际重力矩为：

   `T = 9.80665 × (挂重kg × 挂点水平力臂m + 长臂kg × 重心水平力臂m)`

5. 每个高度分别测正、反两个方向，至少重复3次。记录开始、60秒、10分钟和1小时的位置。先区分长臂弯曲、夹具松动和摩擦面的滑动；不能分清就记录“不确定”。不要把照片里“似乎没动”写成0°。
6. 记录刚开始转动的峰值阻力和持续转动的阻力。可用测力计在已知垂直力臂上拉动，力×力臂为转矩。要计入并扣除/说明重力作用，不能把抬升配重所需的总拉力全算成摩擦。
7. 记录拆下后的压痕、松动与表面变化。若底座、长臂或夹持已经明显变形，这条记录不能用于宣布摩擦方案合格。

0.3°停留漂移、60 mm手持力臂和20 N操作力沿用为**暂定筛选线**，不是用户确认的最终手感或精度。角度读数的不确定度要和漂移一起比较；例如0.29°±0.05°不能判定通过0.3°。

小样用穿透螺钉和背面螺母，便于独立实验；它不能验证拟议M3自定义轴的防松、铝环变形、两侧分配或整臂的手感。只有小样出现有余量的工作窗口后，再带着实测数据修订并验证完整关节。

## 怎样交回数据

复制[空白记录表](measurement_template.json)，每次测量填一份。空白、非有限数值和分辨率不足都会保留为未完成或不确定。当前目录没有用户的实测数据。

在design根目录可运行：

```powershell
.venv/Scripts/python.exe -X utf8 Hardware/PoseDoll44/cad/revO10/evaluate_bench.py 你的记录.json
```

输出只分析这一条小样观察，不会升级成“整关节通过”。没有轴向力实测时不会生成摩擦系数，也不会把目录210 N填入实测栏。

国产微型滑环是另一项独立电气候选，尚不要求和摩擦小样一起购买。先核对LPMS-05D实际供货图纸、引线和版本，再用现有静态采集协议测转动中的导通、错误帧、掉电和恢复；当前没有可连接硬件，未执行该测试。
