# 第一次做 PoseDoll 小样测试：从这里开始

你不需要先买整个人偶的零件，也不需要先买一套实验室仪器。这一轮只验证两件事：碟簧的实际压缩力，以及 PEEK 与金属配对的单面摩擦表现。当前没有实物测量结果。

## 今天的第一步

联系能测「碟簧力—高度曲线」和「受控法向力下的低速起动扭矩」的厂家或检测方。两项可以分开找。先发送本包中的规格、STEP 和任务书，确认对方的夹具、校准仪器、原始数据交付与报价，再购买或加工样件。请对方解释有效量程、分辨率与不确定度是否适合这些小样。

## 买什么

- B 系列碟簧：外径 8、内径 4.2、厚 0.3、自由高 0.55 mm；至少 6 片，3 组两片对合串联。
- A 系列碟簧：外径 8、内径 4.2、厚 0.4、自由高 0.60 mm；至少 12 片，3 组四片对合串联。
- LP6 未填充 PEEK 试片：接触区 ID12 / OD28 / 厚 0.6 mm，3 外耳，至少 3 片。
- M4 未填充 PEEK 试片：接触区 ID5.2 / OD14.8 / 厚 0.4 mm，3 外耳，至少 3 片。
- LP6 金属对偶件：OD34 / ID6.1 / 厚 3 mm；4×Ø2.2 安装孔，分布圆 Ø31，首孔 45°，至少 1 件。
- M4 金属对偶件：OD20 / ID3.1 / 厚 3 mm；4×Ø1.7 安装孔，分布圆 Ø17.8，首孔 45°，至少 1 件。

A8/B8 仅是指南中的尺寸简称。首批数量在询价时确认。外耳不计入 PEEK 接触区外径。金属牌号、表面、平面度、尺寸公差和夹具尚待加工方/检测方确认后才能加工。CAD 的 steel 分类不等于指定了生产钢号。

碟簧参考供应商：[锐尔立中国官网](https://www.raleigh-spring.cn/discspring/)，2026-09-25 核对目录尺寸；实际库存、价格、批次性能未经确认。未填充 PEEK 可向中国加工店询价可追溯原料；[原厂材料识别参考](https://www.ensingerplastics.com/en-us/shapes/peek-tecapeek-natural)不代表指定唯一品牌或接受其目录摩擦系数。

## 谁做什么

你可以整理编号、标签、分装盒、照片和文件；已有卡尺可做内外径初检。精密厚度、自由高、平面度、力、扭矩和角度交由具备能力的检测方测量。初次试验建议委托，不必先购买压机和传感器。

检测方需确认中心导向、平行压板、限位、测力和位移测量，以及单面摩擦夹具与空载阻力处理。不能用手压、螺丝圈数或目录力代替真实测量。网页动画中的夹具仅说明原理，本包没有完整夹具生产图。

## 要怎么测

A：标记并测单片，再测 B 的两串组合、A 的四串组合，记录加载和卸载的真实力—高度曲线、重复条件与组间差异。允许行程根据厂家规定和实际锥高确认。对合串联力不翻倍，行程相加；目录工作点不是最大力。

B：在摩擦区外固定 PEEK 外耳，金属件绕轴转动；先测夹具空载基线。在数个实测法向力设置下，记录单面起动扭矩；同一设置 CW/CCW 各至少 3 次。记录实际施加的停留扭矩，加载停留 60 秒并记录角度变化。先低载荷，再在夹具、材料和已测弹簧允许范围内增加。

原始计划中 LP6 约 0.463 N·m、M4 约 0.304 N·m 是双面关节保持预算，不是单面已测能力。目录力 354 / 210 N 不是必须直接使用的测试载荷。暂定手感筛选线 20 N / 60 mm、漂移 0.3° 不是最终验收标准。同一法向力设置的实测范围不得超过均值 5% 才能作为同组初筛。

## 收回什么

1. 批次、尺寸、金属牌号/表面、温度与装夹照片。
2. 仪器校准编号、测量能力、空载阻力与处理方法。
3. 单片和组合的加载/卸载原始曲线。
4. 每条摩擦记录的样件编号、设置编号、法向力、方向、单面起动扭矩、施加停留扭矩、时长与漂移。
5. 操作人、日期、仪器原始日志和报告。

把这些资料保存在同一个目录后交回项目。可由我们整理模板与日志 SHA256；哈希证明文件未变，不证明实验本身真实。不要在空白模板中填入目录值来冒充实测。

本包 O7-original 保留原始研究任务书、4 个试片实体、尺寸表和空白模板。小样通过后仍需单关节生产设计、受载与重复摆姿测试、单臂与整机验证；当前没有制造放行。
